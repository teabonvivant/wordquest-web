# WordQuest R3.5 · 文字、首次使用、練習流程與默書練習

## 這次交付

在 R3.4 之上做三件事：（1）把家長和孩子看到的中文改成淺白的香港書面語；（2）修好審查找到的首次使用、英文課堂、遊戲街機、默書練習和數學的問題；（3）把默書定位為練習。**這不是商用版**：英文題庫要教師審核、數學內容分量不足、沒有真人錄音、圖片授權文件未齊。審查結論、改了甚麼和沒改甚麼，見 `docs/R3_5_審查與改動報告.md`（結論在最前面）。

和 R3.3、R3.4 一樣，`app/index.html`、`app/sw.js` 不是手改的 12 MB 檔案：`tools/build_r35.py` 先重建 R3.4，再套 `r35_src/patches/` 的補丁模組。每個錨點必須剛好出現一次，否則建置失敗；`<script>` 數量必須不變（40 個）；版本由核心統一改為 R3.5.0。

| 補丁 | 內容 |
| --- | --- |
| `p10_firstrun` | 首頁（一個大按鈕加三個圖案、「更多玩法」摺疊、默書卡）、登入頁、頁頭（沒有「登出」、聲音用字顯示、橫放手機用選單）、底部 5 個分頁（數學不再是浮動按鈕）、離線標示、訪客提示、表單欄位標籤、不認得的網址回到新首頁 |
| `p20_lesson` | 英文課堂：答錯回饋與選項標記、未作答與儲存失敗分開、提示、結果頁、放棄選單、說明入口、舊網址不顯示「完成」 |
| `p30_arcade` | 遊戲街機：大堂、新帳戶 0 金幣、卡片字體與對比、看玩法卡、準備卡、結算卡、觸控／鍵盤說明、回到頂部 |
| `p40_dictation` | 默書練習：加入範圍三步、相片辨認（OCR）篩選與提示、草稿、練習（重試、提示、無聲音後備）、家長報告、範圍管理、15 分鐘家長確認 |
| `p50_maths` | 數學：答案顯示與判卷一致、單位、題目措辭、小標題中文化、做題畫面只留「← 返回」、按鈕 48 px、清走頁尾聲明、家長進度頁 |
| `p90_copy` | 全站文字：把審查的 1,445 句改寫稿（`r35_src/copy/rewrite_audit.csv`）整句比對、套進程式；每個腳本再用 Node 檢查語法；結果記在 `r35_evidence/copy_applied.csv` |
| `p95_fixups` | 整合時發現的前後不一致：家長確認時間（15 分鐘）、「新街機」改「新遊戲」、設定頁舊遊戲數目、簡體字 |

模組之間的次序：`p00, p10, p20, p30, p40, p50, p90, p95`。文字改寫（p90）放在後面，所以各模組新寫的句子不受它影響；p95 放最後，用最終文字做錨點。

## 重建與測試

```sh
python3 tools/build_r35.py                          # 重建 app/、server/（r35_evidence/build.json 記錄雜湊）
python3 tools/build_r35.py --only p10,p20 --out /tmp/x   # 只套某些補丁，供開發
python3 tools/build_r35.py --base-only --out /tmp/r34    # 只輸出 R3.4 文字（A/B 對照用）
python3 r35_tests/run_release.py                    # R3.5 新測試，逐項依序執行（不要並行）
python3 r35_tests/run_behaviour.py                  # 「改前（R3.4）應失敗、改後應通過」的 A/B 證明
python3 r35_tests/run_legacy.py                     # 其餘舊測試（R3.3、R3.4、R3 至 R3.2、街機、smoke）一套一套順序跑，日誌放 r35_evidence/legacy_logs/
python3 r33_tests/run_release.py                    # R3.3 測試（含為 R3.5 更新的字眼）
python3 r34_tests/run_release.py                    # R3.4 測試
python3 tools/package_r35.py                        # 重新產生 PACKAGE_MANIFEST.json 與 SHA256SUMS.txt
```

瀏覽器測試用 Chromium（Playwright，不要執行 `playwright install`）。每套測試都是一份 12 MB 網頁，請一套一套順序跑，不要並行。

`[B]` 標記的檢查在 R3.4 上必須失敗，在 R3.5 上必須通過；`run_behaviour.py` 兩邊都跑並核對。

### 最終測試結果（最終版 `app/index.html`，沙盒內 Chromium 模擬與 Node，非真機）

**一、R3.5 新測試**（12 套，順序執行；最終版 `app/index.html`，SHA-256 `86e699ce…d75d01`）

| 套件 | 檢查數 | 其中 `[B]` | 結果 |
| --- | --- | --- | --- |
| p10 首頁、登入、頁頭、導覽（含 A14 不認得的網址回新首頁） | 95 | 75 | 全部通過 |
| p20 英文課堂 | 173 | 115 | 全部通過 |
| p30 遊戲街機（大堂、卡片、玩法、狀態、其他共 5 套） | 113 | 72 | 全部通過 |
| p40 默書練習（瀏覽器 103、相片辨認篩選 26） | 129 | 85 | 全部通過 |
| p50 數學（判卷與顯示 69、瀏覽器 68） | 137 | 106 | 全部通過 |
| p90 全站文字掃描（畫面上的字） | 16 | 14 | 全部通過 |
| **合計** | **663** | **467** | **0 失敗** |

**二、改前改後對照**（`run_behaviour.py`）：12／12 套通過。467 條 `[B]` 檢查在 R3.4 版本上**全部失敗**、在 R3.5 上全部通過；沒有一條在舊版也通過（也就是沒有「怎樣都會過」的檢查）。一個說明：`p40-dictation` 有 5 條「這一段執行時沒有出錯」的防呆檢查，R3.4 沒有默書練習，那一段根本跑不起來，所以在舊版上無法執行，不算在 467 內。

**三、R3.3 測試**（13 套，約 1,171 項檢查）：全部通過。逐套：p20-pure 26、p30-speech-limit 16、p30-static-cache 30、p30-pwa 19、p20-rescue 80、p20-media-gc 32、p20-gate-dialog 45、p40-arcade-overlay 53、p40-sfx 59、p40-library-checkbox 45、p10-layout 340、p10-hit-test 276、p50-learning-account 150。
最終整批執行時 p10-layout 有 8 項失敗（測試用了一個程式本來就沒有的網址 `#arcade`，R3.5 不認得的網址會回新首頁）；測試改用真正的網址 `#game` 後單獨重跑，340 項全部通過。

**四、R3.4 測試**（5 套）：全部通過。engine-behaviour 46、engine-validity（156 款遊戲設定）通過、browser-rules 8、browser-feel 12、browser-touch 60。`browser-feel` 的「分數跳升」那一項在四次完整執行中偶然失敗過一次（固定只等 600 毫秒），已改為最多等 3 秒。

**五、更早版本的測試**（`run_legacy.py`）：R3、R3.1、R3.2、街機、smoke 共 39 個執行項（R3.3、R3.4 的整批各算一項，其餘 37 套逐套執行）全部「符合預期」。
- 兩個本來就有問題的檔案（`arcade_tests/r1_regression.py`、`tests/integration_checks.py`）是 429 項中 **10 項失敗、419 項通過**，和 R3.4 原版數字完全一樣（數學範本的老問題，與這次改動無關）。
- 16 個舊測試檔（R3.3 的 8 個另計）為了新用字或新畫面位置改過檢查，每項改動和原因在 `r35_evidence/legacy_test_updates.md`。這批測試在 R3.4 原版上全部通過，所以失敗是 R3.5 的改動引起，不是本來就壞。

**六、這些結果的限制**：全部是沙盒內的 Chromium 觸控與手機尺寸模擬和 Node 測試，**不是真機、不是真人兒童、不是教師審核**。測試只能證明「程式照設計做」，不能證明「小朋友看得懂、用得順」。

日誌：`r35_evidence/`（R3.5 新測試與 A/B）、`r35_evidence/legacy_logs/`（舊測試）。為 R3.5 改過的舊測試和原因：`r35_evidence/legacy_test_updates.md`。

## 默書：定位為練習

- 預設「寬鬆」：大小寫不計。家長可選「大小寫要完全一樣」。
- 答錯可再試，最多 3 次，有兩級提示；有提示或看字抄寫答對，會記為有協助，不當成自己串對。
- 畫面不用「成績／通過／交答案」；完成頁只講練了多少，並列出要再練的字。
- 沒有英文聲音的裝置：改用看字抄寫，不卡住。
- 關於教育局的指引：我讀不到 2025 年指引原文，只依「默書屬教學活動」的方向設計。**「佔英文科成績不超過 10%」和「小一首幾個月不應紙筆默書」是傳媒報道，沒有核對原文，程式和畫面沒有引用。**

## 已知限制與未驗證

- **沒有真機**：手機測試是 Chromium 觸控與手機尺寸模擬（390×844、844×390、320×568、768×1024）。iPhone Safari 的地址欄伸縮、軟鍵盤、「加入主畫面」、真實 TTS 聲音都沒有實測。
- **沒有真人兒童和教師**：用字是我按審查稿改寫，沒有母語編輯逐句潤飾；詞庫沒有教師審核。
- **沒有改內容**：英文詞庫（義項、例句、圖片缺口）、數學課程覆蓋和題型、奧數題型。
- **沒有改的介面項目**：全站 38 處瀏覽器原生確認窗（S2-09）、家長首頁重排（S2-10）、「裝置與儲存檢查」開發者頁（S2-19）。
- **沒有改的默書項目**：默書日倒數和分日計劃（D2）、PDF 上載（D10）、離線 OCR 面板（D14）、家長操作量（D18）、OCR 設定（D20）、拼字檢查糾正（D21）、慢速音檔（D26）；也沒有新增詞典條目。
- **語音和圖片**：沒有真人錄音；圖片授權文件、角色圖的 AI 來源、OpenMoji 3 張、封面圖，見報告第 3.5、3.6 節。
- **文字風格**：統一用書面語。**用字是否「像真人寫」要由真人讀過才算數。**
- 家長確認時間由 5 分鐘改為 15 分鐘（有操作自動延長），這是安全與方便之間的取捨，需要你同意。
