### 星星與金幣

沿用 R3.6：全對而且沒有用提示 = 5 星；≥ 90 % 4 星；≥ 75 % 3 星；≥ 50 % 2 星；其餘 1 星。闖關另有合格線（見家長難度）。金幣：某一關第一次拿 5 星 +1（魔王關 +3，首次通過魔王關再 +2）；快速測驗 5 星 +1（每日最多 3 枚）；遊戲「字母獵場」5 星 +1（每日最多 2 枚）。訪客（未登入）可以玩，但不儲存進度，也不給金幣。

### 存放位置與限制

- 闖關進度、難度、角色、任務存在瀏覽器 `localStorage` 的 `wq37-<帳戶>-<孩子>`，**不在「家庭完整備份」之內**，換電腦要另行處理。
- 「單元課堂」（拼字教室）的 20 題考考你不跟家長 5 級難度走（維持固定 8 詞＋20 題）。
- 家長難度會改變：闖關、快速測驗、默書練習的題數與選項。
- 數學、奧數的題目由程式生成，題型已用程式逐題核對答案，但沒有教師審核。

### R3.15 默書「儲存」真正落地

- **記住這部裝置**（`s52_device.js`／`patches/s52_device.py`）：登入、建立帳戶表單有「記住這部裝置」勾選（預設勾選，小字「共用裝置請取消」）。勾選時帳戶 id 另存 `localStorage` 的 `wq52-device:<SESSIONKEY>`；新分頁、重開瀏覽器、主畫面捷徑在第一次讀取資料前恢復登入（帳戶仍存在才恢復，**不恢復家長解鎖**）。登出清除兩處；測試版 Admin 不寫入。
- **訪客按「✓ 儲存」不再假儲存**（`s50_dictation.js` 的 `s50Gate`）：彈出「先登入才可儲存」卡（登入／建立帳戶／取消），不寫入。訪客登入或建立帳戶時草稿不被清除，v20Origin 重設給新帳戶目前孩子；從該卡開啟登入頁時，成功後自動回 #range-new 第 2 步儲存一次。登入頁有「取消，返回選字」。
- **家長解鎖過期**：按儲存先記下待儲存並顯示家長密碼畫面（說明會自動儲存 N 個字），解鎖後自動儲存一次，最後見到成功卡。不延長解鎖時間。
- **編輯鎖**：已登入但這個分頁沒有鎖時不寫入，儲存列上方說明並提供「在這個分頁編輯」（沿用 `data-v23="acquire"`），取得後自動續存。
- **失敗明示**：`save()` 回傳 false、或寫入後讀回的儲存副本沒有這個範圍及字詞時，顯示「儲存失敗，沒有寫入」，草稿保留，不顯示成功卡。
