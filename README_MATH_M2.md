# 學霸星球數學圖卡課堂 M2

從「數學 → 主題課堂」進入新版。這次集中改善小朋友的閱讀負擔及教學呈現。

## 學習方式

- 圖卡選課：六個年級、按數字／量度／圖形／數據等類別找主題。
- 79個普通數學主題各有對應的數學示意圖；6個探索主題使用研究筆記插圖。
- 一卡一重點：大圖、短句、重點字卡，可以回看或聽讀目前卡片。
- 基礎課先用三張卡講清一個示例；應用課加入說理問題及既有教學重點。全部170個章節均使用新流程，不代表170課完整教材。
- 例題一次一個，按「打開做法卡」才揭曉答案與解說。獨立小測仍在交卷後才顯示答案。
- 答錯後分開顯示正確答案卡和步驟說明卡；首次答案、提示及成績保留。
- 原有16種教具仍從「動手試」使用。其他主題保持紙筆／實物活動。

## 開啟

完整程式：`app/index.html`；主入口：`START_HERE.html`；單獨試用數學：`math_course_preview.html`。

使用相同網址、瀏覽器及學習檔案可繼續原紀錄。切換網址或裝置前，請先從家長頁匯出備份。訪客試玩不會跨次保存進度。

## 開發

- 圖卡及示意圖：`math_course_src/course_visuals.js`
- 圖卡版面：`math_course_src/course_visual.css`
- 課堂互動：`math_course_src/course_ui.js`
- 重建：`python3 tools/build_math_m1.py`（沿用既有建置入口，已支援M2）
- 測試：`node math_course_tests/engine_test.cjs`、`node math_course_tests/visual_ui_test.cjs`

圖形由SVG程式繪製，不依賴外部圖片或載入服務。沒有新增追蹤、帳戶或付款功能。

## 驗證與界線

核心15項及15,400次生成／批改案例通過；新增9組課堂渲染及事件檢查通過。完整頁49段、預覽頁11段腳本及Service Worker語法通過。原有43段非M1課堂腳本逐字保持不變。

新增UI檢查在Node環境執行實際渲染函式與事件，使用DOM測試替身；不等同真實瀏覽器、觸控或版面驗收。本輪已檢視數學SVG圖卡，未完成手機／桌面瀏覽器實際排版測試或正式部署驗證。詳見 `docs/math-course/`。

M1來源及舊測試證據保留為歷史資料；目前建置雜湊見 `docs/math-course/BUILD_SHA256.json`，M2提交檔案清單見 `MATH_M2_RELEASE_MANIFEST.json`。
