# 奧數路線 · 單元撰寫指引

給負責寫單元的人（或代理）。只需要寫**資料檔**（`r37_src/oly/p1.js` … `p6.js` 內的單元），不用碰播放器、地圖、闖關引擎。
參考實作：`p1-2 湊十`（`p1.js`）、`p4-1 雞兔同籠`（`p4.js`）；其餘 28 個是草稿（`draft:true`），照同一標準換掉即可。
依據：`設計書.md`（含「研究後修訂」）、`年級對照研究.md`（每級數字範圍、題幹字數、「多一步」的意思；本指引第 8 節摘要）。

## 1. 單元物件（schema）

```js
WQOly.register({
  id: 'p1-2', grade: 1, n: 2,            // id = p<年級>-<第幾個單元>，必須與 grade / n 一致
  title: '湊十', icon: '🔟',              // 單元名、一個 emoji（地圖島、卡片用）
  card: { motto: '先湊成 10',            // 口訣 ≤ 14 字
          example: '8＋5＝10＋3＝13',     // 例子一行
          art: '<svg viewBox="0 0 120 80">…</svg>' },  // 迷你圖解（可省略，會用 icon）
  cover: 'assets/r323/p1-2.webp',        // 可省略（預設就是這路徑）；檔案不存在時自動用 icon 墊底
  lesson: [ /* 5–8 張卡，見第 2 節 */ ],
  gens: { A: [fn, ...], B: [fn, ...] },  // 闖關 A / B 的生成器，各至少 1 個，建議 2–4 個
  verify: q => '答案字串' | null,        // 獨立重算答案（必寫，見第 4 節）
});
```
`register` 遇到格式錯誤會直接丟錯（Node 測試立刻發現）。草稿換成完成版：用同一個 id 再 `register`，並**刪掉** `draft:true`（完成版不能被草稿覆蓋）。

## 2. 課堂卡（lesson）

每張卡一個物件，`t` 決定類型。規則：**5–8 張**、**至少 1 張 predict、1 張 do、1 張 try**、最後一張必須是 `card`、**每個 `say`／`ask`／`reveal` 最多 2 句、每句 ≤ 22 字**、不得有語音／朗讀。所有文字香港繁體。

| `t` | 欄位 | 行為 |
|---|---|---|
| `show` | `say`, `scene:{w,p,still?}` | 播放動畫（`demo()`）；有「重播」鍵。`still:true` = 不自動播，只顯示起始畫面 |
| `predict` | `say`, `ask`, `options:[…]`, `answer`, `reveal`, `scene`（建議 `still:true`） | 先揀答案，再播動畫揭曉；揀完才可「下一步」。答錯也只是提示「差一點」，不扣分 |
| `do` | `say`, `scene:{w,p}` | 可操作工具；達標前「下一步」是灰的，達標亮起。有「示範一次」「重來」 |
| `try` | `say`, `q:{stem, options?, answer, hint?, explain?, why?}`, `scene?` | 一題小試。無 `options` 就是填數字；答錯顯示 `why[該錯答]`（沒有就顯示 hint）；錯 3 次直接給答案 |
| `card` | `say?` | 策略卡預覽（由 `card` 欄位畫），按鈕變「去闖關」 |

`scene = { w:'工具名', p:{…參數…}, still?:true }`。無法用現成工具表達時，可新增一個工具（第 3 節末）。

## 3. 工具目錄（`r37_src/oly/oly_widgets.js`）

共同規則：顏色固定 — 青＝第一部分、金＝第二部分、紫＝總數、粉紅＝差／要找的。每個工具可用**觸控／滑鼠拖拉**、**鍵盤**（Tab 聚焦＋Enter／方向鍵）、**示範**；尊重 `prefers-reduced-motion`（示範直接到結果）。`mode` 由播放器設定（`do`＝可操作，其他＝只顯示），不用寫在 `p` 內。

| 工具 `w` | 參數 `p` | 達標 `check()` | 鍵盤 |
|---|---|---|---|
| `tenframe` 十格框 | `a`、`b`（各 ≤ 10，左框 a 粒、右框 b 粒） | 左框滿 10，合成一條「10」，顯示 a＋b＝10＋餘 | 聚焦右框的點按 Enter 搬過去 |
| `numline` 數線跳格 | `min,max,start,target,steps:[1,2,5],hops:[{n}]`（hops＝示範路徑） | 青蛙停在 `target` | 青蛙聚焦後 ←→；或按「＋n」鍵 |
| `bars` 棒形圖 | `rows:[{label,segs:[{u,c:'a'|'b'|'t'|'d'|'g'|'k',text?,dashed?,rep?,edit?,target?,start?,min?,max?}]}]`，`braces:[{from,to,label,c}]` | 所有 `edit` 段長度＝`target`（`rep`＝重複份數） | 把手聚焦後 ←→ |
| `array` 陣列切開 | `cols,rows,cut,start?` | 切線在 `cut` | 把手 ←→ |
| `pairing` 頭尾配對 | `n`（偶數，≤ 12） | 全部配成和為 n＋1 的對 | 揀一個數按 Enter，再揀另一個 |
| `rowplace` 植樹 | `segments, ends:'both'|'one'|'none', circle?, span?, unit?, item?` | 所有位置放滿 | 點樹或位置按 Enter |
| `dotgraph` 握手連線 | `n`（≤ 8）, `faces?` | 每對人連線一次 | 揀兩個人 Enter |
| `cycle` 轉盤 | `n, labels?, steps(目標), start?, unit?` | 走滿 `steps` 步（可用「一圈」鍵） | 指針 ←→ |
| `sortcards` 排卡 | `cards:[{id,label,emoji?,h?,hide?}], order:[id…], start?, axis?` | 順序＝`order` | 卡片聚焦後 ←→ 換位 |
| `swap` 雞兔假設換 | `heads, legs, a?, b?, pre?`（a／b：`{name,legs,emoji}`；`pre`＝示範用，預先換好幾隻） | 腳數剛好＝`legs` | 動物 Enter 換／換回 |
| `banner` 標題圖 | `icon,title,motto,example` | —（草稿用） | — |

新增工具：在 `oly_widgets.js` 內 `make('名', { mount(host, p, api) { … return {check, demo, reset, destroy}; } })`；用 `fit(host)`、`drag`、`keys`、`sbtn`、`runner(api)`、`burst`（檔內已提供）。要求：觸控拖拉＋鍵盤替代＋demo＋reduced-motion，按鈕 ≥ 44px，成功用 `burst` ＋ `api.sfx('good')`，不用語音。

## 4. 生成器（闖關題）

```js
gens: {
  A: [ (r, p) => WQOly.o(skill, stem, answer, hint, explain, wrongs, calc, accept, extra) ],
  B: [ … ]
}
```
- `r` ＝ 種子亂數（`r()` 0–1）；**不可用 Math.random**。`p.s`（0–1）＝家長難度＋關卡決定的**數字大小**；用 `N(r,p,lo,hi)` 取隨 `p.s` 增大的數，`ri(r,a,b)`、`pick(r,arr)`、`shuffle(r,arr)`、`name(r)`（帶「他／她」）。都在 `const { o, N, ri, pick, shuffle, name } = WQOly.helpers;`。
- `skill` 單元內唯一的題型名（引擎會自動加上單元前綴）；`answer` 數字字串（可 `a/b`）；`hint` 一句提示；`explain` 一句方法＋算式（算式鏈要算得對，測試會檢查）。
- `wrongs`＝其他干擾項（數字）。`calc`＝可選的算式字串（只能 `+ - * / % ()` 和數字），測試會獨立計算並與答案比對。
- `extra`：`{ why, svg, form }`。
  - **`why`**：`{ '<常見錯答>': '一句錯因提示' }`。每個單元每關至少兩種常見錯答要有 why。這些錯答會**一定**出現在選擇題選項中；`why` 的鍵不可等於答案。例：`{ [s-1]: '先湊十，再加剩下的 3，別數少了。' }`。
  - **`svg`**：`'<svg viewBox="…">…</svg>'`，顯示在題幹上方，最大約 240×110；色用 `#3ee6d0`（青）`#ffc94a`（金）`#c3cbf7`（字）。有圖的題目盡量附圖，減少文字。
- **數量要夠**：引擎一關最多要 12 題（難度 5，魔王關 ≥ 10），同一關題幹不可重複。**每個生成器在最高難度也要有足夠多的不同題幹**（`N()` 在高 `p.s` 時只取範圍的上半，範圍太窄會「cannot build question」；測試會抓到）。
- **A 與 B 的分別（設計書 A5）**：A＝直接應用本單元方法；B＝**多一條關係或多一步轉化**（見第 8 節各年級說明），**不可只放大數字**。B 的 `skill` 名不可與 A 重複（測試檢查）。家長難度 1–5 只增減數字大小，不增加步數。
- **`verify(q)`**：由題幹文字（`q.q`）用正則解析數字，**用與生成器不同的方法**（例如逐一嘗試）重算答案，回傳字串；認不到的題型回傳 `null`（完成版單元任何一題回傳 `null` 都算失敗）。
- 題幹字數上限（完成版，測試檢查）：小一 30、小二 40、小三 55、小四 65、小五 75、小六 85。用香港用語（雪櫃、搞清楚……），不用方程式（方程小五才學）。

## 5. 策略卡

`card.motto`（≤ 14 字）、`card.example`、`card.art`（120×80 的 SVG，可省略）。過關 B 時有翻卡特效＋音效，「我的策略卡」頁按年級分組，未得的是剪影。封面圖 `assets/r323/<id>.webp`（由美術另外生成）。

## 6. 規則清單（交付前自己打勾）

- 每張卡 ≤ 2 句、每句 ≤ 22 字；5–8 張；有 predict／do／try；最後是 card。
- 全部數字在入門範圍內（第 8 節）；每級年級與 `年級對照研究.md` 一致，有偏離要在報告寫明理由。
- 沒有任何語音、朗讀按鈕或 TTS 呼叫。
- 至少一個 `do` 工具，能拖拉、能用鍵盤、有示範。
- 生成器純函數、決定性、`verify` 獨立重算；每關至少 2 種常見錯答有 `why`。
- 不可有外部連結、AI 痕跡文字；不編造真人姓名。

## 7. 怎樣單獨測試一個單元

1. 只測題目（秒級）：`node r37_tests/test_oly_units.cjs` ——30 個單元 × A/B × 難度 1–5 × 200 種子，檢查答案重算、無重複題幹、干擾項、why、字數、課堂卡規則。只看自己的單元：`node r37_tests/test_oly_units.cjs 2>&1 | grep p4-1`。
   看樣本題：`node -e "require('./r37_src/oly/load_node.js');const M=require('./r37_src/levels_math.js');console.log(M.make('olympiad',3,0,6,3,1).map(q=>q.q+' → '+q.answer))"`（參數：年級−1、關卡 0–9＝2×(單元−1)＋(0=A,1=B)、題數、難度、種子）。
2. 重建：`python3 tools/build_r37.py`。
3. 看課堂：瀏覽器開 `app/index.html#oly/<年級>/<單元>/learn`，`?c=3` 直接跳第 3 張卡（登入後才存進度）。
4. 自動走一遍所有卡（五種尺寸、無捲動、場景 ≥ 55%）：`WQ33_APP=<app/index.html> python3 r37_tests/t50_oly_path.py`；工具測試看該檔 A4 一節的 `labs` 寫法。
5. 工具實驗室（只看工具，不用整個 app）：`_team_runs/r323-oly/lab/lab.py` 把 `oly_core.js`＋`oly_widgets.js` 直接載入頁面並逐個截圖。
6. 截圖一定要**放大看**：字有沒有被切、對齊、擠迫、模板感。

## 8. 各年級入門範圍（摘自 `年級對照研究.md`）

| 年級 | 數字範圍 | 題幹上限 | 闖關 B 的「多一步」 | 步數 |
|---|---|---|---|---|
| 小一 | 和 ≤ 18（圖像題 ≤ 20）；100 以內只數數、跳數 | 30（理想 22）；每題配圖；不用「恰好」「至少」 | 多一個中間量（前 3 後 4 還要加自己；湊十三個數先挑一對） | 2 |
| 小二 | ≤ 100；週期 2–7 | 40（故事 55） | 多一次換算（棵數↔段數、一輪↔第幾個）或一次湊整配對 | 2 |
| 小三 | 和 ≤ 100（B ≤ 200）；倍數 2–8 | 55；棒形圖輔助 | 多一個隱藏量（先求差、先求一份） | 3 |
| 小四 | 頭 ≤ 15（B ≤ 20）、腳 ≤ 60 等 | 65；表格列已知 | 多一次改寫條件（把條件改成假設法、環形改成段數＝棵數） | 3 |
| 小五 | 序數 ≤ 200（B ≤ 1000）；容斥只兩個圈 | 75；可含「至少」「恰好」 | 多一次轉化（最壞情況再加 1；先求最小公倍數） | 3–4 |
| 小六 | 全部整數；份數 2–3 份；速度 ≤ 100 米／分 | 85；題圖必備 | 多一次單位／對象轉換（全部看成 1、速度和換速度差、一人中途離開） | 4 |

單元收窄（設計書「研究後修訂」）：`p1-3` 只數同一大小（B 最多 2×2）；`p2-5` 週期 2–7；`p3-5` 只做二、三位數×一位數的位值拆分；`p5-4`＝真假推理；`p5-5`＝容斥（兩個圈）；`p6-2`＝按份數分配（不用比號）；`p6-4`＝相遇與追及（第一張卡先教「速度＝路程÷時間」）；和差、雞兔不用方程，用棒形圖／假設法。
