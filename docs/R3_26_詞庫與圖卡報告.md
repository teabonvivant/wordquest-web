# R3.26 詞庫、詞形、圖卡（2026-10-23）

## 做了什麼
- **詞庫**：原有 6,057 項（人手整理）保持不變、優先；新增 8,961 個開源詞典詞條（按語料頻率挑選），合共約 15,000 個詞頭。生成程式 `tools/build_wordbank.py`，資料 `r37_src/wordbank_*.json`。
- **詞形**：294 個不規則變化（went→go、mice→mouse、bacteria→bacterium…）進入對照表 `WQ_FORMS`；規則變化沿用 `s55_morph.js`（修正 caves→cafe 誤判）。`s55SameWord` 新增「詞族」判斷：play／plays／playing／played、go／went／gone、child／children 一律視為同一個字，即使兩個拼法都是詞庫條目；glass／glasses、bus／busy 等不同字則保持分開。
- **圖卡**：263 個詞以 Unicode emoji 對應（只收名稱完全一致者）；另有 473 張原創字卡（`app/assets/r326/words/`，192px webp，約 4 MB，離線快取 cache-first），由 Codex 畫成 4×4 貼紙拼圖後以 `tools/slice_sheet.py` 切開；身體部位加紅圈標示。遊戲（射擊、跑酷）仍用原本 emoji，不受影響。

## 已知限制
- 釋義屬「詞典參考義」，未逐詞配例句；多義詞由家長在匯入時揀意思（沿用原機制）。
- 字卡以具體名詞為主；抽象詞、虛詞不配圖（避免誤導）。身體部位以紅圈標示，仍較依賴文字提示。
- 以頻率排名 16,000 內的詞為主，不是完整大詞典（ECDICT 全庫 340 萬條，大部分是罕見詞或專有名詞）。
