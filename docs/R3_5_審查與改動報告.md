# WordQuest R3.5 · 商用審查與改動報告

2026-10-03 · 審查對象：R3.4（`app/index.html`）· 改動後版本：R3.5.0

## 一、結論（先看這裏）

**R3.4 不能商用。R3.5 把介面、文字和默書練習做到可以給家長和小朋友試用；英文題庫、數學內容和語音仍然不能商用，因為差的不是程式，而是教師審核、內容分量和真人錄音。**

我的判斷：這一版**適合內部試用和找少量家長試玩**，不適合收費推出。要收費，最少要做完這三件事：（1）請香港小學英文教師逐項審核詞庫，（2）錄製真人讀音，（3）補完圖片授權文件。數學先收窄範圍，比寫全課程更快過關。

> **默書的兩個外部說法我沒有核實。** 你提到教育局把默書視為教學活動、小一頭幾個月不應進行紙筆默書，以及傳媒報道新指引要求默書佔英文科成績不超過 10%。我讀不到 2025 年指引原文，所以程式和這份報告只依「默書是練習」這個方向設計，沒有把「10%」「小一首幾個月」寫進任何畫面。

## 二、我做了甚麼

- 七路審查（英文內容、英文教學流程、數學、圖片和語音、介面、文字、默書）。每一路都開真實瀏覽器，用 Chromium 模擬手機（390×844、844×390）和電腦；英文詞庫抽樣 320 條逐條讀；數學抽查模板和判卷；介面量過 86 個畫面。
- 然後改 R3.5。改動用建置腳本重建，不是手改 12 MB 的檔案：`python3 tools/build_r35.py`。
- 每個改動有測試；「改前應失敗、改後應通過」的檢查另跑 A/B 對照。
- **限制**：沒有真機、沒有真人兒童、沒有教師。畫面和流程在 Chromium 模擬；內容正確與否我只能抽樣，不能代替教師簽核。

## 三、逐項審查

### 3.1 英文內容（題庫、知識庫）：未可商用

- 抽樣 320 條詞：**128 條沒問題（40%）；127 條有缺口（多數沒有例句）；57 條中文意思或用語有問題（18%）；8 條義項選錯（2.5%）**。
- 詞庫 607 個詞，**297 個（49%）沒有圖也沒有例句**。
- 義項選錯的例子：`lot` 解作「一塊地」（小學生學的是 a lot＝很多）、`chest` 解作「箱子」（應是胸口）、`bank` 解作「河岸」（應是銀行）。
- 沒有教師簽核：資料的編輯狀態字串自己寫着 AI 編輯、未經教師審核。
- 家長看得到的文字混入編輯內部備註 41 處；台灣式用語 8 處。
- 題型：聽力題和讀字題用同一批詞；「找錯」題固定把首字母換成 z；干擾項來源單一。
- 全部 166 項：4 項嚴重、77 項中等、85 項輕微。完整清單：`docs/audit/2026-10-03/english-content/`。

R3.5 **沒有改這部分**。原因：改詞義要由教師決定，我改了反而會把未審核的東西包裝成已審核。內部備註和簡體字已由文字改寫清走。

### 3.2 英文教學與測試流程：未可商用 → 可小範圍試用

審查找到 4 個嚴重問題，R3.5 全部修了：

1. **孩子答錯後看不到答案**（回饋卡被底部導覽蓋住）→ 回饋卡在第一屏內完整看得到，寫「答案是 cat。」再加一句用這個字造的短句；正確選項標「✓ 答案」加粗框，選錯的選項標「再看看」加橙色虛線框（不用紅叉，不打擊孩子）。
2. **「沒選答案」和「儲存失敗」共用同一個警告**，都帶「重試儲存」→ 分開。沒選答案只在輸入處提醒「錯了不扣金幣」；儲存失敗才出現警告，說明發生了甚麼和下一步，按鈕叫「再試一次」；不再重複彈出提示。
3. **新帳戶第一次進遊戲街機撞牆**：0 金幣卻寫「已開放」，按鈕灰色、按了沒反應 → 看玩法卡寫「已解鎖。玩一次要 1 枚金幣，你現在有 0 枚。」，灰色按鈕換成「去賺金幣：做一個小練習」，一按就開始今天的小課。金幣規則沒有動。
4. **每頁頂部都有版本號和「待審核」聲明** → 清走；只在家長設定的「關於這個程式」留一行。

另有：提示寫成「提示：第一個字母是 x，一共 N 個字母。」；結果頁寫「做了 8 題，答對 4 題」，並說明一組有 12 個步驟、8 題的關係；結果頁三個按鈕為「再練一組」「去遊戲街機」「回首頁」；放棄動作收進右上角「⋯」選單，叫「放棄這組」，不再和主按鈕並排；左上角叫「暫停」；沒有進行中的練習時開舊網址，不再顯示「這一輪完成了、0 金幣」，改為「今天還沒開始，按「開始今天的小課」。」；說明入口統一叫「怎樣玩？」；鍵盤 Tab 的次序改為先作答、最後才是放棄。

**沒有改**：間隔重溫的接線、學習診斷、跨科整合——這些是功能，不是修補。

### 3.3 默書：定位改為「練習」

審查前，默書是考試式的：預設「嚴格默書：大小寫必須正確」，答錯不能重試，完成頁寫「成績／通過／有效任務」。R3.5 改為：

- **預設寬鬆**：大小寫不計（Pencil 當 pencil）。家長可改為「大小寫要完全一樣」，要自己選；舊設定如果沒有明確選過，會轉為寬鬆。
- **答錯可再試**：最多 3 次。答錯時題目不收，出現一句鼓勵和提示；第二次提示更強（給字母遮罩）；選擇題選錯的選項會變灰，不能再選。重試次數在重新載入頁面後還在。
- **有協助就記有協助**：用過提示答對，狀態是「有提示時答對」，不會當成自己串對；看字抄寫的答案也不算自己串對。
- **不用考試字眼**：按鈕叫「檢查答案」和「看提示」（不再是「交答案」「看示範」）；完成頁只寫練了多少、答對多少，並列出要再練的字，附「再練這些字」按鈕。
- **沒有英文聲音的裝置**：不卡住。顯示「這部裝置沒有英文聲音，請家長讀給孩子聽或改用其他裝置。」，孩子可按「看字抄寫」練習；聲音播不出來也不擋答案。
- **沒有中文意思的字**：改用聽讀音的方式問，不再出空白題；家長頁列出哪些字缺中文。
- **學習步驟**涵蓋範圍內全部的字，不只首 5 個。

家長上載相片到練習的路徑（只檢查功能，沒有改 OCR 本身）：

| 問題 | 修了甚麼 |
| --- | --- |
| OCR 一律預選全部候選，連標題、日期、亂碼也選上；空白紙和手寫相也顯示「已辨認」 | 只預選像英文字的項目；辨認得不清楚時寫「辨認結果不太清楚」，不預選；清楚時才顯示成功和數目 |
| OCR 失敗顯示「OCR loader unavailable」「Failed to fetch」和檔案路徑 | 改成「這張相片沒有辨認到英文。請重新拍照，也可以直接輸入文字。」；技術細節收在「詳細資料」裏 |
| 草稿重新載入頁面就消失 | 草稿自動存在這部裝置，重新打開還在；有「重新開始」 |
| 儲存後跳到冗長的「離線教材」頁，看不到成功 | 儲存後直接到這個範圍的頁面：「已儲存「…」，共 N 個單字」，並有「請孩子開始練習」 |
| 三個步驟擠在一頁（約 2,000 px 長），主按鈕灰色又沒說明 | 分三步：相片或文字、檢查單字、儲存；按鈕灰色時旁邊寫明原因；摘要是頁面的一步，不再是彈出視窗 |
| 沒有預設單元名；示範範圍用假日期冒充「今次默書」 | 預填「默書 M月D日」，紙上有單元名和日期就取用；示範範圍標「示範」，不再有日期，可刪除 |
| 家長沒有說明怎樣拍相 | 頁面顯示拍照提示 |
| 孩子可自己切換使用中的範圍；儲存後不能改名 | 範圍頁要家長確認；可改名 |
| 家長確認 5 分鐘就過期，容易中途要再輸入 | 15 分鐘，有操作會自動延長 |
| 家長報告滿是開發者用語 | 狀態改為「還沒練習／選對過／有提示時答對／最近自己串對／隔日複習也串對」，並有說明和「再練這些字」按鈕 |
| 窄屏長字（grandmother）斷字；夥伴卡佔去三分之一螢幕 | 長字不斷開；夥伴縮成一條（不高於 90 px） |
| 兒童首頁找不到學校範圍 | 首頁主按鈕下面有「今次默書練習」卡，顯示範圍名稱、單字數和日期，按「開始練習」 |

**沒有改**：D2（默書日倒數和分日計劃）、D10（不收 PDF）、D14（離線 OCR 面板）、D18（家長操作量）、D20、D21（拼字檢查糾正 teh、sch00l）、D26（慢速音檔）；也沒有新增詞典條目（天氣字、ice-cream 等仍未收錄）。這些是新功能或需要真機，排進下一輪。

### 3.4 數學：未可商用

- 課程覆蓋估算約 **17%–29%**。每個單元只有 1–4 個技能，每個技能固定 3 條模板；高小每單元只有 1 個入門選段。
- 全庫**沒有兩步或以上的應用題**；R3 的 282 條模板**沒有一條設有干擾項**，答錯只能回報「再看清楚題目」。
- 奧數的「基礎／進階／競賽」三層其實是同一批 5 個題型，沒有和差倍、植樹、盈虧、行程等本地奧數核心題型。
- **嚴重 Bug**：題目要求「請用小數」，答對 19/100 被拒；但訂正卻顯示 19/100（自相矛盾）。
- 一共 39 項：9 項嚴重、21 項中等、9 項輕微。完整清單：`docs/audit/2026-10-03/maths/issues.csv`。

R3.5 修了：答案顯示和判卷自相矛盾（訂正按題目要求的格式顯示）、單位和「又」的接受規則、題目措辭（「選出最準確的名稱」「= ？」「3 條」）、答案洩露括號、英文小標題改中文、做題畫面只留「← 返回」和進度、按鈕加大到 48 px、清走三段頁尾聲明（只在家長進度頁留一條短說明）。**做題畫面連夥伴列也拿走了**（題目和輸入框才能在手機第一屏出現），所以做題時不再有「答錯時刺刺安慰一句」「答對時換表情」；夥伴仍在數學首頁、工具和奧數頁出現，設定在數學首頁。這一項要你決定，見第五節第 12 項。

**沒有改**：課程覆蓋、應用題、干擾項和誤解診斷、奧數題型。這要新增內容，由教師定範圍。**建議先收窄為「小一至小三 · 數與計算」測試版**：那裏模板最多，錯的最少。

### 3.5 圖片：未可商用，差的是授權文件

畫面質素大致可以（詞義圖 275 張、內置配圖 132 張、自家插圖 39 張）。要商用，缺的是授權：

1. **詞義圖和內置配圖**：來源是 Noto Emoji，但標籤寫 OFL-1.1，Noto 彩色圖像一般另以 Apache-2.0 發行；要補授權全文、版本號和取得日期。
2. **OpenMoji 3 張**：CC BY-SA 4.0 要求相同方式分享，改作成 PNG 屬改作，封閉產品有爭議。**改用 Noto 同義圖，刪除這 3 張。**
3. **角色圖（6 位夥伴）是 AI 生成**，版權難以登記；原稿海報隨應用一併發佈（約 16 MB），任何人都驗得出。**商業包只留處理後的 webp；原稿和提示詞放內部存檔。**
4. **封面圖構圖和跑酷類遊戲相近**，有相似度和商譽風險。建議換掉。

另外：詞義圖有 5 張與詞義錯配、12 張單複數不符（見 `docs/audit/2026-10-03/media/words_image_audit.csv`）。

R3.5 **沒有動圖片**。

### 3.6 語音：未可商用

- 整個產品**沒有一個預錄讀音**。英文發音全靠裝置的 Web Speech：有沒有英式聲音、口音和質素都不能保證；雲端聲線還會把文字送去供應商（私隱）。
- 家長同意後會從 Wikimedia Commons 下載英式錄音；逐檔授權不一，商業版不應預設分發。
- 音效是程式合成，音量很細（約 −32 至 −26 dBFS），嘈雜環境可能聽不到。
- OCR 腳本從第三方 CDN 載入，沒有完整性校驗（SRI）。建議自行託管固定版本。

R3.5 只做了一件事：裝置沒有英文聲音時不讓孩子卡住（見 3.3）。**真人錄音是商用的必要條件**，建議找香港小學英文老師按詞庫錄。

### 3.7 介面：未可商用 → 可小範圍試用（未經真機驗證）

審查共 46 項：7 項嚴重、22 項中等、17 項輕微。R3.5 處理了大部分。我在 390×844、844×390、320×568、768×1024 和電腦尺寸逐頁量過。

| 問題 | 結果 |
| --- | --- |
| 首頁 3 秒看不懂，「開始」在首屏外 | 首屏有全寬的「開始今天的小課」、問候（含孩子名字和年級）和三個大圖案「英文／數學／遊戲」；其餘收進摺疊的「更多玩法」 |
| 新家長找不到「建立帳戶」 | 登入頁首屏是兩張大卡：「第一次使用：建立帳戶」「已有帳戶：登入」；錯誤提示留在欄位下面，不會 2.8 秒就消失；密碼可「顯示密碼」；遊戲街機宣傳放到表單下面 |
| 答錯看不到答案；沒選答案和儲存失敗混淆 | 見 3.2 |
| 街機新帳戶撞牆；準備卡字太細 | 見 3.2；準備卡、結算卡字體 16 px 以上、按鈕 48 px 以上，26 款逐款量過沒有被切 |
| 版本號和聲明露面 | 清走 |
| 浮動數學按鈕遮住內容 | 取消，改為底部第 5 個分頁「數學」 |
| 頁頭：登出貼着家長和聲效；名字膠囊一按就跳去密碼頁 | 孩子頁頭沒有「登出」，登出搬到設定（會先問一次）；名字只是標示，不能按；聲音開關用字顯示「聲音：開／關」 |

### 3.8 文字（給家長和小朋友讀）：不適合 → 大致合格

審查 4,177 句不重複的畫面文字（共 4,953 處）：

- **1,445 句（34.6%）要改**；其中 156 句「必改」（嚴重度乘曝光 ≥ 20）。
- 開發用語露面：版本號 30 句（V28、V30、R3.4）、驗證器式錯誤（「整數超出範圍」）、登入頁的 `Admin / 1234`。
- 句子太長：孩子畫面常見 20 至 40 字長句，夾雜「證據」「獨立」「延後重溫」「義項」「派幣」這類成人行政用語。
- 不一致：「金幣」有 6 種寫法；同一個地方有 5 個名字；27 句簡體字或內地用語。

R3.5 的做法：把審查給的改寫稿（每句附原因）逐句套進程式，**整句比對、只換整句、不換片語**，避免把程式識別字也換掉（例如篩選用的「新街機」同時是代號，改名時要一起改）。結果：

- 1,415 句已改（共 1,655 處）。30 句沒有直接套：23 句已在別的模組換了新說法，或因為夾在長句裏另外補改（共 5 句是我另外補的）；3 句是單字太短、怕誤傷其他地方；4 句同時是程式代號，其中 2 句另外全站改名。完整清單：`r35_evidence/copy_applied.csv`。
- 套完後，程式內每個腳本用 Node 檢查語法；再用瀏覽器走過 14 個畫面，掃禁用字詞（版本號、工程用語、簡體字、測試密碼等，`r35_tests/p90_copy_text.py`）：**0 條命中**。唯一容許的版本號，是家長設定「關於這個程式」那一行。
- **語體統一用香港書面語**（不用「嘅、咗、係」），因為家長也讀；對 7 歲孩子的句子拆短。

**母語編輯再讀一遍仍然需要**：我是用規則和審查稿改的，不是逐句潤飾。
