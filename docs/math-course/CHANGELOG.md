# CHANGELOG — HK-M1

## 學生介面

正常數學入口改為主題課堂、考考自己、再練一練、動手學數學。首頁數學星不再用舊60關進度冒充新85個主題的進度。舊普通數學關卡入口轉到新課堂，歷史生成器及紀錄保留，不重算舊分數。

課名、操作按鈕及解說使用較短的香港中文；學習不設倒數。基礎與應用章節分開；應用加入比較、辨錯及說明方法，不單靠增大數字。

## 題目與批改

主要範圍修正見 `CONTENT_CHANGES.json`。例：小二2N2減法限兩位數，小二2N5不再出四位數減法；小六百分數普通題庫不再出折扣題；分數最簡形式要求按年級分開。修訂後模板使用 `.C1` ID；歷史模板放在 archived，以免過往作答被新答案重判。

獨立作答與提示作答分開。小測不提前批改，不因空白答案而無法交卷；交卷後原答案不可覆寫。算式的數值及單位正確，但程式未能識別其解法時，列為待家長／老師核對，不直接給全錯。

測驗同一份卷內不重複相同題幹與答案；優先避開目前保留的已看題目。題目較少時使用較短小測，不強行湊數；所有選中單元必須至少一題。需要使用之前見過的內容時，清楚標示重溫，不當作新題掌握證據。

## 進度與獎勵

只有至少5道新題、全對、無待核對解法的單主題小測，才會進入5星金幣條件；按主題及階段防止重複領取，實際金幣沿用原有錢包及每日限制。教具操作、探索筆記、已打開課堂不當作已掌握。

重溫以平台1／3／7／21日安排。當天看解答後答對，不會直接清除延後重溫提醒。80%僅是平台「本次小測達標」顯示，不是教育局標準，也不是整單元精熟認證。

## 儲存及整合

新資料存於原有math sidecar的`courseM1`，共用原有帳戶／孩子隔離、驗證、衝突檢查及獎勵佇列。新版核心驗證保留舊資料並校驗新欄位。訪客不假裝永久儲存；切換孩子不複製訪客測試紀錄。

英語、奧數、街機的主要程式未被取代。工具iframe僅開allow-scripts，不開same-origin，以來源視窗與token核對操作回報。服務工作者更新cache版本；未進行線上PWA部署。
