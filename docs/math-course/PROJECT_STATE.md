## 本輪重點

在已發布的M2網站重現小三分數課「只教分數表示，練習卻跳去比較分數」的問題。修正普通數學79個主題、158個章節的抽題範圍與教學示範連結；6個探索單元的12個開放章節維持原流程。

新增32個自行編寫的讀圖、幾何及生活應用題型。普通數學現有417個模板（含舊模板及79個說理模板）；M3章節採明確選定的題型，不以舊說理選擇題補足題數。模板變更數字不等於更多概念或完整覆蓋。

教學使用本課實際例題及數值，配分步計算和相符圖像。主要入口為跟我學、換你做、小測；原16件教具及例題回顧仍可選用。分數輸入、逐步提示、空白練習保護、逐題訂正已改。
