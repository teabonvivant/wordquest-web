# M3 教學與測驗審查

日期：2026-10-11（香港）。底本：GitHub main `6c299a2`。

本輪先在已發布網站以訪客開啟「數學 → 主題課堂 → 小三 → 一份是幾分之一？」。M2 教學以四等份示意圖介紹分數，點進「練一練」的第一題卻問「1/7 和 1/6，哪個分數較大？」而沒有比較圖。這是實際重現的教考銜接問題，不是只根據程式推測。

桌面畫面也顯示：完整頁首、導覽、訪客條、課名、五個流程入口及陪伴角色佔用大量高度，第一張教學卡的關鍵句在畫面下方。使用者的「資料有，但學得辛苦」有具體依據；前版把教材縮成圖卡，沒有解決逐步教法及抽題範圍。

## 修正

1. 為79個普通單元的158個章節定義實際題型範圍。每個會出現在該章練習／小測的題型都有該章示範。例題及新題使用不同數值；原有未完成草稿保留，不默默改題。
2. 教學直接使用該章例題的數據，展示具體計算。退位減法顯示借位後數位，分數比較顯示同樣大的整體，異分母加法寫出通分數值。題名改成實際教授的目標，移除未實作內容的過度承諾。
3. 新增32個自行編寫的題型，包含生活應用、讀尺、量杯、秤、時間線、象形圖、幾何辨認、地圖方向、列式、逆向平均數及水位排水體積。保留單一數值題與列式題的區別；沒有宣稱已支援公開卷的所有多小題、作圖或自由文字評分。
4. 主要路徑是「跟我學 → 換你做 → 小測」。工具與例題回顧保留為額外入口。教學句先於大圖顯示，移除課中重複側欄，保留放大本題圖。
5. 分數用分子／分母輸入格；提示按步展開；空白練習不能誤記成一次錯答。交卷後按題展開圖、原答案、正確答案及步驟。
6. 原有模板ID、已交卷答案、家長紀錄及歷史題目仍可重現。這次改教法與新出題範圍，沒有重算舊成績。

## 參考與界線

- [教育局：小學數學科學習內容（2017）](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/ma/curr/pmc2017_tc.pdf)：核對年級、範圍及數學概念界線。例：小二2N2的加法可用三位數，減法限兩位數；小三分數不要求約分。
- [考評局：公開評估試卷](https://www.bca.hkeaa.edu.hk/web/TSA/zh/PriPaperSchema.html)：閱讀2025小三3MC1及小六6MC1，參考讀圖、填充、生活應用及列式的結構。題目自行編寫，並非複製試卷。

公開評估不能代表每間學校的課本編排、試卷深度或評分準則。本輪沒有取得使用者學校的課本或測驗卷，也沒有香港小學教師或學生參與驗收。程式檢查只證明指定行為和運算，不證明孩子已能自學。未重寫全部官方學習重點，亦未把170個章節稱作170課完整教材。
