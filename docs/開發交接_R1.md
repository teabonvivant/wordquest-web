# R1 開發交接

## 問題根源與接駁

原英文 V32 的 `db`、`activeChild`、`save` 等變數在最末主程式的封閉作用域內；旧數學整合器的偵測邏輯無法透過全域名稱存取，會退回獨立模式。R1 不是匯出整個資料庫，而是在 `installMediaEvents(); render();` 前注入 `patches/host_bridge.js`，建立凍結的 `window.WQMathHost` 介面。

Maths 的 `createHostBridge()` 優先採用 API v1 橋接。主頁新增科目卡片，透過 `WQMathApp.open(route)` 開啟已嵌入的 Shadow DOM／dialog。英文原始內容及素材仍在主 HTML，沒有 iframe 複製登入或另外開錢包。

## 模組界線

- `profile()`：只回傳 id、account、name、grade、persistent、balance。
- `assertWritable()`：沿用英文頁寫入租約，拒絕載入損壞及過期 writeRevision。
- `beforeOpen()`：拒絕在未保存英文練習、匯入或進行中街機上直接疊加數學；取消語音／音訊。
- `award(request, scope)`：只接受目前孩子 sidecar 內已提交的 outbox 事件；比對事件欄位、日期及擁有者，呼叫原 `COIN28.task`，保存成功才返回金幣數。
- `parentAllowed()`／`openParentGate()`：沿用英文本機家長密碼與解鎖時段。
- `afterClose()`：重新繪製英文餘額及頁面。

Maths 使用 `wqm-state-v1:<英文帳戶ID>:<孩子ID>`。兩條數學路線以每筆 attempt.track 區別。英文金幣仍是原孩子 `stars` 欄位（畫面稱金幣）；`arcadeV28` 保留原有任務結算紀錄。

## 獎勵一致性

Maths 先提交 outbox，再同步英文錢包，最後 ACK（標為 settled）。英文事件鍵加 `math:` 前綴，與原英文 key 空間分離，但仍共用當天獎勵進度與上限。

當英文成功而 Maths ACK 失敗，下次重試會由英文任務去重機制回傳 0，然後補 ACK，不重派。當英文保存失敗，回復英文記憶體快照並保留 outbox。較早於七天或明顯未來的待結算事件保留以供備份，拒絕自動派發。這是瀏覽器本機一致性措施，並非伺服器防作弊或可信競賽計分。

## 刪除資料

英文 `save` 包裝器比較前次保存的 children 與新 children。移除孩子時，先清理對應 Maths 主 state 及 `:before-restore` 副本；失敗便拒絕這次英文保存，原刪除函式回復 db 快照。英文保存失敗時恢復已暫存的 Maths 原字串。瀏覽器突然關閉在跨 key 操作中途仍不是真正資料庫交易，這是未消除的設計限制；後續商用版應使用具交易能力的持久層。

## 核心修正

`tools/patch_math.py` 的錨點必須恰好出現一次，否則停止建立，不默默修改未知版本。

1. 需要題目的課堂步驟必須存在非空題目 queue，避免「可恢復但沒有答案欄」。
2. 舊獨立版的損壞孩子名單可降為清楚標示的暫時訪客，而不覆寫原名單；可匯出原文字。整合版仍由英文管理名單。
3. 整合訪客在同一頁關閉／重開時保留暫時 Store；不宣稱頁面重載後訪客資料永久保存。
4. 儲存失敗關閉前明確確認；取消保留目前畫面，確定才離開。
5. 提交後將鍵盤焦點移到回饋區，不掉回 document.body。
6. 不僅導航／設定要家長驗證，完成頁「查看學習進度」也必須通過同一 gate。

## 重建與重跑

一般使用者不需要執行以下步驟。

```sh
python tools/build.py
python tools/verify_build.py
node tests/legacy_rerun/tests/core_checks.cjs
python tests/legacy_rerun/tests/generation_oracle.py
python tests/integration_checks.py
```

整合 DOM 測試需要 Python Playwright 及 Chromium，範例路徑為 `/usr/bin/chromium`。可按本機安裝位置調整測試腳本。版本由 `evidence/environment.json` 記錄；這不是使用者執行程式的依賴。

## 不可混淆的事情

- R1 並非 V33 或 0.1.3；沒有恢復其原創街機及角色素材。
- 原本 1,000 項審核與新一輪結果是兩個不同基線；originals 不被覆寫。
- 測試夾具、假故障及 PBKDF2 呼叫轉接均明確隔離，未寫入交付程式。交付 `app/index.html` 沒有 storage／locks 假介面。
- Native localStorage／多分頁鎖／真正頁面重啟、手機真機、外部 OCR、語音自然度仍需實機驗證。
- 合併備份與舊獨立數學到英文孩子的人工配對遷移沒有實作，不能直接改 backup.owner 當作安全遷移。
