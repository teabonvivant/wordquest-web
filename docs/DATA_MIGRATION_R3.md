# R3 備份、搬移及恢復操作

## 兩種匯入不同
「家庭完整還原」替換目前家庭的學習資料，會列出將還原的孩子與筆數，需家長驗證及勾選確認。它不是將兩個家庭自動合併。帳戶登入憑證不在備份，換裝置要在目標先建立／登入本機家庭。

「搬入舊學員紀錄」只合併指定孩子的支援格式數學JSON（format=wordquest-maths，version=1）。這是另外的按鈕，不再強迫舊獨立版學員ID必須與英文帳戶ID相同。不是任何來源／損壞／未知版本均可讀入。

## 舊數學合併規則
先關閉或完成目前數學課堂。核對舊學員姓名與年級、目標孩子；選錯孩子時取消，不能靠猜測自動分配。

保留已提交作答、原評分、較新的技能掌握紀錄及可接受的課堂統計。相同模板、種子、作答時間及答案的事件去重；同一備份雜湊不能重複搬入。舊未完成課堂不搬入。舊錢包和待派獎勵不搬入，不補派金幣。目標孩子的原有金幣不變。

合併超過5000筆作答或300節課堂時，整次拒絕並保留舊備份，不截尾製造成成功。合併前保留原數學快照；若儲存失敗，應停止並匯出目前可讀資料，不重覆點擊。

## 家庭JSON內容
全部孩子的英文資料、普通數學／奧數狀態與數學還原快照、街機局面及紀錄、跨科時間和配額、角色偏好、自訂圖片／聲音／備註。單份上限140MB，單個媒體DataURL最多3000萬字元，媒體總和最多1.1億字元；不支援不安全SVG媒體、損壞Base64等輸入。

JSON未加密，姓名與學習紀錄可直接閱讀；SHA-256只驗證檔案是否被改動，不等於加密、身份認證或防造假。請私下保存，不放進公開GitHub／公開下載區。

## 防止舊備份重置獎勵／時限
同來源家庭還原時，既有孩子以目前金幣、現行街機結算狀態及每日獎勵台賬為準，使用時間取各科較大值；不將已使用的時間倒退。不是伺服器反作弊：本機使用者仍控制瀏覽器，不能把這機制當作付費資產安全方案。

## 中斷恢復
資料交易先建立復原日誌，再寫入英文、數學及媒體。寫入失敗會嘗試還原；還原也失敗時保留日誌並停止其他寫入。家長驗證後按「恢復中斷交易」。日誌遺失時不會假裝成功；先保留現場，不要清空瀏覽器資料。原生跨儲存交易恢復仍需真機斷電／關閉驗收。

## 清除範圍
「清除目前帳戶資料」清除目前家庭學習、數學、復原副本、角色偏好、自訂媒體及跨科資料；保留登入帳戶本身、重新建立「小朋友」空學習檔案，不影響其他家庭。這不是刪除整個登入帳號或清除已下載到硬碟的備份。
