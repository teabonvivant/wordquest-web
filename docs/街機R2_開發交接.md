# 街機 R2 開發交接

## 版本決策

V33 main `WordQuest_V33_Original_Arcade_Package.zip`、audit `WordQuest_V33_Playtest_Audit_Package.zip` 及V32 redesign ZIP只有檔案記錄，raw materialization仍失敗。因此採用已交付R1原HTML重建，不能宣稱取回V33原碼。

採納先前對話的五款名稱及玩法方向；特別處理跑酷過易、平台重生、手機畫面、音量。這些是歷史需求參考，不將先前報告的測試數字搬來當本輪成績。原創向量場景和合成音，不複製參考遊戲的角色、地圖或音樂。

## 模組

`arcade_src/engines.js`：五個WQGame子類別，登記全新ID，原21個ID不改。

| ID | 引擎 | 主要狀態 |
|---|---|---|
| ruins-courier | RuinsCourierR2 | distance / lane / jump / slide / obstacles |
| cloud-island | CloudIslandR2 | p / platforms / checkpoint / coins / enemies |
| star-patrol | StarPatrolR2 | shots / drones / orbs / boss / shield / power |
| lighthouse-well | LighthouseWellR2 | p / camera / platforms / floor / parachute |
| harbor-volley | HarborVolleyR2 | p / ai / ball / touches / points / servePause |

所有模擬以秒計，宿主將每步限制在1/60秒。draw只讀取狀態，不推進亂數或遊戲。音樂拍點跟隨模擬，而非獨立setInterval。Canvas 800×560保持不變，CSS依容器調整顯示尺寸；觸控座標按實際矩形換算。

`arcade_src/audio.js`：宿主內的音訊適配器。用戶按開始或試音解鎖；音效／配樂分開GainNode，兩者都服從總開關，零音量不排程。最多64個短音節點；pause停止節點及suspend。總線即時音量取消舊automation，再設定gain.value，避免保留舊值。沒有外部MP3或承諾錄音品質。

`arcade_src/host_extension.js`：音量UI、放大／fallback、可讀即時狀態及成績頁。公開WQR2Runtime只提供唯讀版本和音訊狀態，不公開db。WQR2.games只包含引擎及metadata，並非用戶資料。WQMathHost的API版本和橋接識別保持R1，因其契約未變。

`arcade_src/arcade.css`：觸控尺寸與fullscreen排版；放大時隱藏裝飾gamebar，不能讓它產生隱含grid列搶走畫面高度。

## 快照與錢包

繼續使用v28 envelope（v,id,d,r,state），每個新引擎另有engineVersion=1。WQRewards.encode/decode保留原序列化規則；快照保存亂數狀態，不保存Canvas、AudioNode或按鍵集合。還原清除輸入。WQGameSchema先核對建構器欄位和通用深度／大小，再執行WQR2Validate語義規則。

C.ids在尾部追加5個，不重編原ID。普通新遊戲0項複習可看可玩（須有金幣），飛行與深井預設5項複習；家長可按既有方式開放／暫停。bests最多78格。新分數不轉成金幣。原始學習派幣、每批5次和家長規則不變。

資源與snapshot預檢在扣款前。保存失敗回滾扣款；已開局保存失敗則暫停並呈現重試，保留durable舊局面。無原生資料庫／雲端伺服器，不能稱為金融級或防作弊。

## 重建

```
python tools/build_arcade_r2.py
python arcade_tests/syntax_check.py
node arcade_tests/core_tests.cjs
python arcade_tests/browser_arcade.py
python arcade_tests/browser_safety.py
python arcade_tests/browser_compatibility.py
python arcade_tests/r1_regression.py
python tools/write_r2_docs.py
python tools/verify_r2.py
python tools/package_r2.py
```

建置器由`originals/R1/index.html`讀取基底，以精確唯一anchor修改4段原腳本，再加入新引擎與CSS。每個anchor不符便停止，不能默默套錯版。瀏覽器測試需開發機Python Playwright及Chromium；一般使用者只開預建HTML。

`tests/harness.py`是R1測試轉接器，由R2測試沿用。明示記憶體localStorage、Web Locks和WebCrypto API替身；crypto計算本身用Python標準hashlib，但不代表已測原生WebCrypto。page.set_content源於環境封鎖導航。AudioContext/AnalyserNode為原生，並非音效mock。

測試帳戶及餘額是夾具。browser測試有僅加到記憶體HTML的診斷bridge，正式app不包含__arcadeQA／__compat。引擎測試使用deterministic seed，不能拿當真人留存或學習成效。

## 維護注意

- 不要重新執行封存於originals/R1/tools的工具覆蓋新成品；根目錄舊名稱已轉接R2。
- 累計時間只用正常frame，背景、blur、長停頓即暫停，不補扣命。
- 增加新的序列化欄位時，更新建構器與WQR2Validate；勿將DOM/函式放進存檔。
- 生命和host run.lives每步同步；terminal狀態不可再覆寫勝負。
- 重生點必須對應安全平台及其正確高度；保護時間再次越界要安全復位，不能任由位置變成不可序列化的遠處。
- 排球用分數而非三格生命展示，末局第四觸球也要先重設計數才能保存。
- 新增音量需同步宿主DB validator，否則save／reload會丟掉設定。
