# WordQuest R3.4 中文用字審查報告

審查對象：`app/index.html`（R3.4）所有給孩子和家長看到的中文。編輯立場：香港中文編輯與兒童產品文案顧問。唯讀審查，沒有改動任何程式檔。

## 一、結論（先看這裏）

**目前的中文還不能直接給孩子和家長閱讀。** 用字大致通順，宣傳口號也很少，但有三個問題會在試用階段暴露出來：

1. **開發用語直接露面。** 孩子和家長會看到「V28 備份」「V30 學習版」「R3.4」等版本號（共 30 條字串）、驗證器式的錯誤訊息（如「整數超出範圍」「搬移收據格式錯誤」），以及登入頁的 `Admin / 1234` 測試密碼。
2. **句子太長、詞太硬。** 孩子畫面常見 20 至 40 字的長句，而且有「證據」「獨立」「延後重溫」「義項」「派幣」這類成人行政用語。
3. **用字前後不一致，還有 27 條簡體字或內地用語。** 同一個「金幣」有幣、星、金幣、個、粒、枚六種寫法；同一個地方至少有街機、遊戲區、大廳、大堂、挑戰區五個名字；遊戲說明和首頁有「填满」「切换」「词」「准备」「图形」等 10 條簡體字。

數字摘要（以唯一字串計，共 4,177 條；按出現位置計共 4,953 處）：

| 項目 | 數目 | 比例 |
|---|---|---|
| 需要改寫（A 至 E 任一項） | 1,445 條（1,702 處） | 34.6% |
| 其中「必改」（嚴重度×曝光 ≥ 20） | 156 條 | 3.7% |
| 其中「應改」（≥ 12） | 523 條 | 12.5% |
| F 沒有問題 | 2,732 條 | 65.4% |

各類比例（一條字串可有多個標籤，所以相加會超過需要改寫的總數）：

| 類別 | 說明 | 字串數 | 佔全部 |
|---|---|---|---|
| A | 太複雜（長句、術語、多個條件） | 975 | 23.3% |
| B | 翻譯腔、說明書腔、口號 | 90 | 2.2% |
| C | 非香港用語、簡體字、標點 | 27 | 0.6% |
| D | 含糊，沒說下一步 | 212 | 5.1% |
| E | 用語不一致 | 524 | 12.5% |

按對象和位置看，問題最集中的地方是：家長頁（43.8% 需改）、少見的錯誤訊息（75.4%）、首頁（36.2%）和結算畫面（30.5%）。課堂中的字串有 29.5% 需要改。

**建議的處理次序：**

1. 先改 27 條簡體字和內地用語（C 類，半天可完成，風險最低）。
2. 再統一貨幣和遊戲區的名稱（見第四節），一次過套用。
3. 然後處理「必改」156 條（第五節列出頭 40 條）。
4. 把版本號、測試密碼和驗證器訊息移出孩子和家長看得到的畫面（需要程式改動，見第九節）。
5. 套用改寫後，用 `rewrite.csv` 的「原文」欄逐條核對，再重跑 R3.3、R3.4 的測試。

R3.4 自己新增的 78 條字串（含少量字串碎片），有 17 條要改（21.8%），比整個程式的 34.6% 乾淨，但最值得注意的是兩個**不屬於用字**的問題：橫放手機時進度行被截成「124/15…」，以及補丁用 UI 文字當錨點，改字可能令「動感效果」開關無聲消失（第六節）。

## 二、範圍和方法

- **來源：** 用語法樹從 `index.html` 內 40 段內嵌腳本、靜態 HTML 和內嵌 CSS 取出所有含中文的字串，得 5,220 個單位，合併後得 **4,177 條唯一字串、4,953 處顯示位置**。拋出的 `Error(...)` 訊息會經提示框顯示，所以也算在內。
- **不計：** 題庫和詞庫（WQ30Data、WQ_SHARED_REFERENCE、課程資料、媒體目錄的中文註解）、示範資料、開發註解和內部驗證器。這些資料的中文另有同事審查。
- **審查：** 每條字串依對象（孩子／家長／兩者）和位置（首次使用／首頁／課堂中／結算／家長頁／少見）分類；先用規則標出可疑字串（931 條），再逐條人手判斷，規則誤報 113 條，另有 627 條是規則沒抓到、人手加上的。
- **驗證：** 改寫稿用程式檢查 `${…}` 佔位符、emoji、引號和換行是否保持原樣；全部通過。
- **瀏覽器核對：** 用 Chromium（390×844 手機、667×375 橫放手機、1280×800 桌面）走過首次使用、孩子首頁、英文和數學課堂、遊戲街機、家長頁、設定、離線教材和多個出錯畫面，共 39 張截圖，詳見第七節。畫面上看到的每一段中文，都找得到對應的取出字串，或屬於上述不計的資料。

## 八、日後寫字的原則

給日後在這個程式加字的人，一頁版：

**孩子看的字**

1. 一句約 12 字，最多 15 字，一句一件事。
2. 告訴孩子要做甚麼（按、選、看、再試），不要說明系統發生甚麼。
3. 用日常字：看、做、試、玩。不用：證據、獨立、掌握、判定、啟用。
4. 出錯不嚇人、不說教：「讀不到，請再試一次」，不是「系統錯誤，請勿重複操作」。
5. 要提及金幣得失時，說清楚：扣多少、可不可以取回。

**家長看的字**

1. 結果放第一句，原因和做法放後面。
2. 一句一點。條件多就用編號或分段。
3. 專有名詞第一次出現時用一句話解釋，之後用同一個詞。
4. 不要銷售語氣：「全新」「強大」「輕鬆」「一站式」。
5. 提到資料風險時，講「會不會丟失」「可不可以救回來」，不講內部機制。

**兩者都適用**

1. 全站用第四節的詞彙表。新增概念先加進表，再寫字。
2. 書面語為主，不夾口語字（喺、嘅、唔、咗、冇、佢、睇）；港式音譯詞（朱古力、雲呢拿）可以用，但要全站一致。
3. 標點全形：，。；：！？「」。數字和英文與中文之間放一個半形空格。
4. 不放版本號、檔案名、`localhost`、`JSON`、`HTTPS` 等術語在孩子可見的位置。
5. 不要把 UI 文字當程式錨點。需要時用 `data-` 屬性。
6. 禁用：進行……操作、予以、溫馨提示、讓我們一起、不僅……更……、被……所……、旨在、致力於。
