# R3.21 三款新遊戲設計書（字母砲台・字母迷宮・字卡征途）

分支 `r321-arc3`（worktree `/home/workspace/wordquest-web-dev-arc3`）。與 R3.20 階段 2（主目錄）並行，**不得修改** `s70/s71/s72*`、`s35_arcade*`、街機 26 款任何檔案。

## 一句目標
三款新遊戲，每款的**主操作**就是一種學習能力；英文與數學共用同一套玩法；有 10 關×多世界闖關；精美、有音效特效、手機觸控＋桌面鍵盤都好玩；學習深度由玩法本身承擔，不是「答完題再玩」。

| 遊戲 | 全域 | 主操作 | 英文訓練 | 數學訓練 |
|---|---|---|---|---|
| 字母砲台 `WQ37TD` | `td_game.js` | 看義／聽音即時拼寫或心算，發炮 | 看中文義拼出英文（回想速度）；Boss 按音節分段 | 敵人頭上是算式，輸入答案發炮；多路來襲排優先 |
| 字母迷宮 `WQ37Maze` | `maze_game.js` | 在迷宮中按序吃字母／數字，躲避追逐 | 聽音＋義，按序吃字母拼字（序列記憶、抗干擾、b/d 類近似字陷阱） | 吃答案數字；條件吃（倍數、單雙、等值分數）訓練分類 |
| 字卡征途 `WQ37Card` | `card_game.js` | 回合制出牌：先解題才能出牌，出牌順序與能量取捨決定勝負 | 拼寫出牌；怪物弱點＝音節數／字母數／首字母（逼孩子分析單詞） | 算式出牌；怪物弱點＝單雙、倍數、大小；湊傷害 |

## 驗收標準（商用版必須全部達成；達不到只可稱預覽）
**學習深度**
1. 每關 8 個學習項（`items`）；開局有 **預習卡**（8 張，圖＋中文＋讀音＋音節拆分，可點讀、可跳過）。
2. 答錯 → 暫停世界，顯示**學習卡**：正確答案大字（≥ 40px 手機）、讀兩次、最少停 2.0 秒才可繼續；數學另有一行 `explain`。答對 → 短確認（≈0.9 秒，不蓋過玩法）。
3. 答錯的項目**回流**：同一關內 2–4 個項目後再出現，最多回流 2 次；回流項目的第一次答對仍計「非首次答對」。
4. 結算報告逐項顯示：首次答對／答對／答錯、用時；答錯項目列出正確答案。全部由 `GX.Learn.result()` 產生，遊戲不自算星級。
5. 星級由**首次答對率**決定（不是分數）：≥95%=5★、≥85%=4★、≥70%=3★（合格）、≥50%=2★、其餘 1★。不可靠打怪或反應速度過關。
6. 5 級難度（host 傳 `difficulty` 1–5）只改：時限／速度、提示量（1–2 級有首字母提示、3 級有提示鈕、4–5 級無提示）、干擾量、迷惑程度。**題目內容難度由 host 的「世界(年級)×關卡」決定**，不由 `difficulty` 決定。
7. 玩法不能讓「不看題目也能贏」：任何怪物／得分／分叉都必須經過答題。

**玩法與手感**
8. 每款至少：連擊倍率、隨機事件或道具、Boss 關（第 10 關，用音節或多步題）、5 級難度、暫停選單、重開、靜音鈕。
9. 音效全部 WebAudio 合成（由 `WQ37GX.audio` 提供）：每個動作有聲音；音樂可關；`prefers-reduced-motion` 時特效減量但仍有回饋。
10. 特效：粒子、震屏（≤ 8px，尊重 reduced-motion）、浮字、連擊火花、擊殺／通關慶祝；全部走 `WQ37GX.fx`。
11. 手機（390×844、360×640 與橫屏 844×390）：觸控、一屏放得下、不需向下拉、按鈕 ≥ 44px；桌面（1440×900）：鍵盤全程可玩。平板 768×1024 正常。
12. 效能：手機 4× CPU 限速下平均幀 < 8ms、最差幀 < 33ms；canvas 文字／圖片預先快取，不每幀建立。
13. 無 console 錯誤；`destroy()` 後無殘留計時器／監聽／AudioContext 洩漏。

**視覺**
14. 沿用 SmartQuest 銀河品牌（深藍紫底、金色重點、玻璃卡片）＋已統一的圖示庫；美術為 Codex 生成的角色／怪物素材（`app/assets/r321/`，webp，單張 ≤ 60KB）＋ canvas 程式繪製光影。**不得**只用 emoji 當主角。
15. 少說明文字：用圖示、卡片、動畫示範；首次進入只給 1 張「怎麼玩」動畫卡（≤ 12 字說明）。
16. 目視驗收：390 與 1440 截圖逐屏放大檢查文字、對齊、截字、重疊。

**整合（host，不在遊戲檔內）**
17. 三款在遊戲星各有入口；闖關地圖 = 科目切換（英文／數學）＋世界分頁（英文 8 世界、數學 6 世界＝小一二…小六）＋10 關，沿用現有 `r37NodeHTML` 地圖樣式。
18. 關卡解鎖：同一款同一科目的上一關過關，或該關對應的英文單元／數學課堂已過關（學過的可直接玩），或 Admin。進度存 `r37LvKey('td-en'|'td-ma'|'mz-en'|'mz-ma'|'cd-en'|'cd-ma', w, s)`。
19. 金幣：首次過關 +1（Boss +2），5★ 首次 +1；錯題寫入既有錯題機制（見 wiring 實作）。
20. 家長後台的難度 1–5 與題目年級的設定沿用現有 `r37DiffN`。

## 內容契約（host → 遊戲）
```
WQ37XX.start(container, opts) -> { destroy(), pause(), resume() }
opts = {
  subject: 'english' | 'math',
  items:   Item[]            // 4–12 個，一關的學習項
  review:  Item[]            // 可選，更早關卡的弱項（間隔重溫）
  difficulty: 1..5,
  level: { w, s, boss:boolean, title, icon, hue, grade },   // grade 如 '小三' 或 '詞彙 3'
  character: { id, icon, img, name, perk },
  sound: boolean,
  speak(text, lang)          // host 語音（可無，GX 會退回 speechSynthesis）
  syllables(en) -> 'car·pet' // host 音節拆分（可無）
  mode: 'level' | 'free',
  onFinish(result) -> coins, // 結算時呼叫一次
  onNext(), onExit(), title
}
Item (word) = { id, kind:'word', zh, en, emoji, img?, ex?, syl? }
Item (math) = { id, kind:'math', q, a, explain, hint, check(input)->bool, pad:'digits'|'frac' }
```
`GX.Learn` 接受這些 item；答案判斷：word＝忽略大小寫的完全相等；math＝`item.check(input)`（host 提供，已處理 `3/4`、小數、全形）。

## 共用核心 `WQ37GX`（`gx_core.js`，由總監寫，三款都用）
`GX.audio(on)`、`GX.fx(canvas, opts)`、`GX.pad(root, opts)`、`GX.ui`（預習卡、學習卡、結算卡、暫停、教學卡）、`GX.Learn`（隊列／回流／星級／報告）、`GX.fit`（DPR 與尺寸）、`GX.css`（共用樣式）。細節看檔首註解。**三款不得自建音訊、粒子、結算或星級邏輯。**

## 世界／年級對應（host）
英文 8 世界（萌芽草原…未來太空站，現有 `R37_TRACKS.english.worlds`）；數學 6 世界＝`WQ37Math` 的 `WORLDS`（小一二／小二／小三／小四／小五／小六）。關 s（0–9）取英文單元 `(w,s)` 的字，或 `WQ37Math.make('math', w, s, n, diff, seed)` 的題。`s===9` 為 Boss。

## 每款細節（建議，不是硬性；硬性只有上面的驗收標準）

### 字母砲台
- 橫向 3–4 條跑道（手機 3 條），敵人從右向左走向基地；敵人頭上顯示中文義＋圖／算式；玩家選目標（自動鎖最近，點擊可改）並輸入。
- 拼對一個字母＝小炮削血（拼到一半也有用）；全拼對＝大炮一擊必殺，連擊升級砲火（火→冰→雷）。拼錯字母：該字母抖紅、不扣血、連擊歸零；同一敵人錯 2 次：高亮下一字母並記為「非首次」。
- 低難度手機字母盤為「答案字母＋干擾字母」（洗牌），高難度為全 QWERTY；桌面一律實體鍵盤。數學用數字盤（分數年級加 `/` `.`）。
- Boss：長詞分音節，每音節一層護盾，逐段拼；數學 Boss＝兩步題。
- 事件：隨機「流星雨」（短暫放慢全場＋雙倍金幣）、「冰凍」道具；基地 5 顆心（難度改）。

### 字母迷宮
- 格子迷宮 11×9（橫）／9×11（直）；角色逐格移動（滑動、方向鍵／WASD、虛擬十字鍵）。每答一個字重新排布字母；幽靈 2–4 隻（追擊／伏擊／巡邏三種 AI）；魔法墨水（能量球）讓幽靈暫時可被吃（＋分，但不影響學習星級）。
- 英文：頂部顯示 中文義＋圖＋喇叭，下方槽位顯示已吃字母；吃錯字母 → 幽靈加速 3 秒＋該字記非首次；高難度加入近似字母（b/d、m/n、p/q）。
- 數學：吃答案數字；另有「條件吃」關型（倍數／單雙／等值分數，依年級由遊戲內部生成，答案由遊戲判定，題幹文字清楚）。
- 事件：隨機傳送門、牆壁暫時打開、幽靈暫停。每個字完成彈一張迷你字卡（中文＋圖＋讀音）。

### 字卡征途
- 一關＝一場戰鬥（Boss 關為雙階段）；牌庫＝該關 8 個項目（可混 `review`）。每回合抽 5 張，能量 3；牌的費用按難度（字母長度／題目步數）1–3。
- 流程：選牌 → 解題（拼寫或計算）→ 成功才生效；錯＝牌破損（本回合報廢、答案展示、之後回流）。怪物有「意圖」（下回合攻擊／護盾）與「弱點」（音節數、字母數、首字母屬性；數學：單雙、倍數、大於／小於）；打中弱點×2。
- 牌種：⚔攻擊、🛡護盾、❤治療、✨抽牌（按項目特徵確定性指派，並圖示化，少文字）。同一項目本場答對 3 次進化（★），威力加成。
- 手感：抽牌飛入、翻牌、出牌軌跡、擊中閃光、怪物受擊／死亡動畫、傷害浮字、回合切換橫幅。
