# R3.5：舊測試改了甚麼，為甚麼

R3.5 刻意改了用字和幾處畫面結構，所以 R3.3 的測試有一部分要跟着改。原則只有一條：**測試要驗的行為不變，只換成新的字眼或新的畫面位置**。沒有一條檢查因為「跑不過」而被刪走；唯一刪掉的是「浮動數學按鈕」的檢查，因為那個按鈕已經按設計拿走，改為驗證「數學分頁」。

每項改動都附原因，方便日後覆核。沒有列出的測試檔，內容一個字都沒動。
