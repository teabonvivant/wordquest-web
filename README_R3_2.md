# WordQuest R3.2 · 保存驗收與阿峰動作候選版

## 這次交付

以 R3.1 完整程式增量升級；保留英文、普通數學、奧數、六位森林學園角色及26款街機。本版重點是家庭資料流程保護、原生裝置自檢，以及阿峰在「雲島探險」的分肢動作。**這是驗收候選版，不是原生保存／手機真機全部驗證完成的商用版。**

## 開啟及升級

1. 在舊版的家長頁匯出「家庭完整備份」，保留舊ZIP。不要以清除瀏覽器資料作升級方法。
2. 解壓整個ZIP。直接開 `START_HERE.html` 可選完整程式、動作檢視、報告及本機驗收說明。
3. Windows 要測原生保存，使用 `START_WINDOWS.cmd`，保留開啟的命令視窗。它使用現有 PowerShell，不需要 Python。啟動器這次未在 Windows 真機執行驗收。
4. 有 Node 的開發者可執行 `node server/local_server.mjs`，使用 `http://127.0.0.1:8765/app/index.html`。兩個啟動器不要同時佔用同一連接埠；不要把本機伺服器直接改為對外開放。
5. 使用同一瀏覽器、模式及網址。更換主機名稱、連接埠或瀏覽器可能看不到舊資料；請用自己的家庭備份還原。**本ZIP不含你的瀏覽器內真實學員紀錄。**

## 已完成的資料流程修正

- 家庭匯出期間暫停其他寫入與操作；教材圖片／音訊仍在處理時拒絕開始。等待媒體和校驗期間，重複匯出、普通保存、媒體寫入／刪除均有保護。
- 摘要校驗完成後再次核對家庭身份、家長授權、寫入權及資料快照；若中途有變動，不產生混合版本的備份。
- 匯出檔案與原有匯入上限保持一致：140,000,000 UTF-8 bytes。過大時明確拒絕，不提供已知不能還原的檔案。**本輪使用邊界規則及故障注入，沒有完成140 MB真機記憶體壓力測試；匯出不是串流實作。**
- 復原日誌只可回寫目前家庭允許的儲存位置；拒絕其他家庭、帳戶驗證登記、未知位置及格式損壞的主資料。拒絕時保留中斷標記，暫停其他寫入，不把失敗當作復原成功。
- IndexedDB 被其他分頁阻擋時，立即提供可處理的失敗，不無限等待；若舊開啟請求其後才成功，會關閉多餘連線。
- 家長頁新增「裝置與保存檢查」。可匯出無姓名、無答案、無帳戶密碼的狀態報告。這是當下狀態，不是重開驗證證明。

## 阿峰：雲島探險動作

待機、跑步、起跳、下落、落地緩衝、短衝、受碰撞及完成共8個狀態。手臂、前臂、腿部、頭部、耳朵及背包分層繪製。短按反方向時先回應操作方向，放手後保留朝向，不因尚未消散的慣性立即轉回去。

動作取自實際遊戲時鐘、速度、着地、扣生命及完成狀態；暫停即停止。視覺狀態只放在 WeakMap，不加入存檔，不改物理、碰撞、生命、分數、金幣或題庫。系統減少動態效果設定會減少次要擺動。

`app/afeng-animation.html` 可切換狀態、暫停、逐格、轉向和查看姿態數值。**目前是按阿峰設定製作的簡化向量角色，並非海報原畫等級的高清逐格素材；另外五位的完整遊戲動作仍未全部製作。**

## 在自己的裝置驗收（不用安裝測試程式）

先以本機啟動器開完整程式，再從家長頁 → 家庭備份 → 裝置與保存檢查 → 開啟本機驗收頁。

驗收頁只用 `wq-r32-device-check:` 專用記號及專用IndexedDB，不讀寫學員帳戶或金幣。它分開記錄原生 SHA-256、localStorage、IndexedDB Blob、同頁 Web Locks、真正第二分頁競爭、重新載入、以及包含你人工確認的關閉重開。缺少API、被封鎖或未操作，都不算通過。

先按「開始檢查並儲存記號」，再做重新載入及第二分頁。最後完全關閉瀏覽器，再開相同網址，核對上次記號；只有你確實完成關閉重開後才勾選人工確認。匯出 `WordQuest_Native_Device_R32.json`。**API自檢通過，不等於完整學員備份和跨版本搬移已通過。**

完整應用仍須逐項核對：英文／數學作答、金幣、街機暫停局面、不同孩子、角色偏好及自訂媒體；換乾淨瀏覽器還原自己的備份前先另作保留。詳見 `docs/R3_2_原生驗收表.md`。

## 本輪測試及限制

本輪重新執行的最終結果見 `docs/R3_2_驗收報告.html` 和 `r32_evidence/RELEASE_RESULTS.json`。功能與資料測試只使用明示測試帳戶、人工案例和生成題目，不能代表真實學生成效。

本環境兩次實際嘗試普通本機HTTP導覽，均得到 `ERR_BLOCKED_BY_ADMINISTRATOR`。因此：

- 原生 Chromium 關閉重開、原生應用多分頁競爭、完整跨瀏覽器還原：**未能執行完成**。
- 主程式DOM測試使用明示localStorage/sessionStorage、Web Locks、WebCrypto替身；家庭媒體／復原日誌測試也使用I/O替身。真正DOM、鍵盤、選單、下載、Canvas及部分音訊實際執行。
- 本機驗收頁本身沒有上述替身；已驗證它在受限環境不會誤報成功。這不等於其原生API全部通過。
- Node伺服器另有真正迴路HTTP與真實檔案讀取測試；這不是瀏覽器持久保存測試。
- Windows啟動器、Safari、實體iPhone／Android、真實默書照片OCR、真人發音聆聽、教師與學生試用，本輪均未完成。
- 沒有擴充全部官方教學重點、補完六位高清動作圖、接入付費聲線，或把大型離線OCR模型下載進ZIP。

## 開發及重現

- `tools/build_r32.py`：以 `originals/R3_1/app/index.html` 為基礎增量重建，不讀取使用者帳戶。
- `r32_src/`：阿峰骨架、日誌規則、主程式接入、本機驗收頁及動作檢視來源。
- `r32_tests/run_release.py`：循序跑本輪規則、DOM與HTTP回歸；不用原生保存替代品的結論去聲稱實機通過。
- `r32_tests/native_acceptance.py`：另啟動臨時本機服務、使用一次性瀏覽器設定檔，透過UI建立測試家庭及執行原生流程。無測試替身，不會接入日常瀏覽器設定檔。在此環境只執行到導覽封鎖；後續步驟尚未完成實跑。開發者須先安裝Node、Python/Playwright及其Chromium。
- `r32_tests/integration_full.py`：完整366模板DOM版本，供完整重跑；本輪最終回歸只重新抽測均勻分布的12個模板，沒有重新獨立驗算全題庫。
- `r32_evidence/initial_*`：保留開發時的失敗及中斷，不混入最終通過總數。
- `originals/R3_1/`：本輪被更改的原R3.1檔案。舊版報告是歷史結果，不能當成本輪新驗收。
- `PACKAGE_MANIFEST.json`、`SHA256SUMS.txt`：完整包校驗。程式重建後應重新生成清單，不可沿用舊雜湊。
