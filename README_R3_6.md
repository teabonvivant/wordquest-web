### Admin 測試帳戶

- 在本機（`file://` 或 `localhost`）打開，登入頁有「進入 Admin 測試」連結；也可在網址後加 `?mode=admin-test`。測試區的帳戶卡已填好 `Admin / 1234`。
- 進去後：26 款遊戲全部打開而且免費；每個單元都可以開始；有「測試中心」連結到各個部分；可切回正常規則（要扣金幣）。
- 測試資料和家庭帳戶分開存放。
- **正式網址（https）沒有這個入口**：沒有連結、沒有測試橫幅、`Admin / 1234` 登入不了、`/#admin` 顯示找不到。
- 這是測試用的功能，不是有後台權限的站長帳戶。

## 重建與測試

```sh
export WQ36_BASE_DIR=/path/to/r35-tree          # R3.5 的檔案樹（commit 52137c4）
python3 tools/build_r36.py                       # 重建 app/、server/（r36_evidence/build.json 記錄雜湊）
python3 tools/build_r36.py --out /tmp/o36        # 輸出到別處，不改倉庫
python3 tools/build_r36.py --base-only --out /tmp/r35   # 只輸出 R3.5 文字（A/B 對照用）
python3 r36_tests/run_r36.py                     # R3.6 新測試（7 套），逐套依序執行
python3 r36_tests/run_behaviour36.py --out /tmp/ab36   # 改前（R3.5）應失敗、改後應通過的 A/B 證明
python3 r36_tests/run_r35suites.py               # R3.5 的 12 套測試（已按新規則更新預期）
python3 r36_tests/run_legacy36.py                # 更早的測試：R3.3、R3.4、R3 至 R3.2、街機、smoke（掃描輸出內容，不只看結束碼）
python3 tools/package_r36.py                     # 重新產生 PACKAGE_MANIFEST.json 與 SHA256SUMS.txt
```

瀏覽器測試用 Chromium（Playwright，不要執行 `playwright install`）。每套測試是一份 12 MB 網頁，請一套一套順序跑。`[B]` 標記的檢查在 R3.5 上必須失敗，在 R3.6 上必須通過。

## 已知限制與未驗證

- **沒有真機**：測試是 Chromium 的觸控與手機尺寸模擬（390×844、844×390、320×568、768×1024）。iPhone Safari、軟鍵盤、「加入主畫面」、真實英文聲音都沒有實測。
- **沒有真人兒童和教師**：星星門檻（全對才 5 星）是否太嚴或太鬆，要看孩子實際玩了才知道。
- **沒有改內容**：英文詞庫、數學課程覆蓋和題型、奧數題型。
- **金幣收入很少**：5 星才有 1 枚，每天最多 5 枚（含一次獎勵）；最貴的遊戲 4 枚。這個比例我按你說的「要有挑戰」定的，見報告第五節。
- **Admin 測試帳戶**只在本機可用；`1234` 是公開的測試密碼，不要放進任何真實帳戶。
- 做到一半的題目，在開新練習或到另一個區（數學／奧數）時會直接丟掉，沒有確認。這是你的要求（第 8 項），但孩子誤按會失去進度。
