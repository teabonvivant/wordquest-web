# 學霸星球數學學習與測驗優化 M1

本提交整合 R3.9 底本及 HK-M1 數學更新。**正式網站部署尚未驗證。**

## 立即試用

打開`math_course_preview.html`，可單獨試用新版數學，不必登入。瀏覽器下載器若只顯示文字，請把HTML交給Chrome／Edge／Safari開啟。訪客不永久保存進度；家長可在家長手冊建立本機檔案。

## 完整學霸星球

解壓全部檔案，打開`START_HERE.html`或`app/index.html`。Windows可用`START_WINDOWS.cmd`；有Node.js可執行`node server/local_server.mjs`，依終端顯示的本機地址開啟。應完整解壓，不能只從ZIP內打開HTML。

初次測試請保留原程式，不覆蓋正在使用的檔案。既有學員請先從原程式家長頁匯出家庭完整備份。這個交付包沒有任何真實學員資料。不同網址／瀏覽器／本機檔案位置的儲存可能不同。

## 改了甚麼

課堂按官方85個單元編排170個基礎／應用章節；79個普通單元接入部分既有教材及新增說理題，6個探索單元保留開放活動。不是170課完整教科書。16件可操作教具，其餘以紙筆／實物活動銜接。

小測選年級及單元，交卷前無提示／答案，交卷後逐題給答案和做法。提示作答、首次獨立作答分開；錯題接回重學與延後重溫。未作答、未識別算式、不同合理分數寫法有分開處理。

已修正一批年級範圍錯置及分數批改要求。舊題ID與歷史作答保留，不重判舊成績；英文、奧數及街機模組沒有被本次數學介面取代。

## 開發及驗收

新版可編輯來源：`math_course_src/`；已整合的實際產物：`app/index.html`；自動重建：`tools/build_math_m1.py`；測試與證據：`math_course_tests/`、`math_course_evidence/`。

詳細狀態、改動、測試結果、已知限制及下一步，見`docs/math-course/`下五份文件。部署前必須做原生瀏覽器／真機、完整家庭備份還原及教師逐目標驗收。
