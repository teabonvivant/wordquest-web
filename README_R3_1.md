# WordQuest R3.1 · 森林學園角色整合版

## 開啟
先解壓整個 ZIP，再開啟 START_HERE.html，選「開啟完整程式」。一般使用不用安裝 Python。網站包括原有英文、普通數學、奧數及26款街機。

## 本輪實際新增
六位新角色是烈烈老師（老虎）、柚柚老師（狐狸）、糖栗老師（小熊貓）、波波（水獺）、刺刺（刺蝟）、阿峰（山羊）。使用本次新繪的六張海報，製成六個肖像與30個表情裁切，並把六張概念圖放入角色介紹。圖片已內置於 app/index.html，顯示學伴不需要連線取圖。

角色出現於英文首頁／教學／回饋、數學／奧數／教具、街機大堂與準備或暫停介面。這是畫面與學習陪伴接入；街機玩家本身仍保留R3的原有動作繪製，並沒有冒充完成六角色逐格跑跳／發球動畫。

在「認識學習夥伴」或數學的「學伴設定」選擇自動分工／固定學伴。可隱藏、精簡頭像及切換短暫進場動效。新設定預設關閉動效；已保存舊偏好會保留。系統減少動態效果設定會覆蓋進場動效。

數學切換角色只重繪學伴區，不重繪題目，不丟棄尚未提交的數字、算式、單位或選項。獨立測試及模擬卷收起角色；角色不接收學生原始答案，不改判分、提示級別或金幣。

## 舊紀錄
本輪不更改學員識別碼、題目識別碼、街機識別碼、學習存檔格式或金幣規則。每位孩子的角色偏好保留原有儲存位置，新增可選 guide 欄位；舊版沒有該欄位時採自動安排。家庭完整備份包含新偏好，舊英文單科備份不包含。

升級前在舊程式匯出「家庭完整備份」。新版本使用不同網址、瀏覽器或本機檔案位置時，不保證自動看到舊紀錄；在新程式用家長頁還原自己的備份。本ZIP不含使用者裝置內的真實學員紀錄。
