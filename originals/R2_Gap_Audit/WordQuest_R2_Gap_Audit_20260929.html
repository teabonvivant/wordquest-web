三、逐項問題、修正方向及驗收

B01 · 已重現程式缺陷先修正

清除目前帳戶後，預設孩子的數學資料仍然保留

實際結果：在測試帳戶完成兩次數學作答、建立還原副本後，按「清除目前帳戶資料」。名字重設為「小朋友」，但同一 c_demo 識別碼仍讀到兩次作答、未完成課堂及 before-restore 副本。

影響與界線：清除不完整；使用者以為已重設，實際仍可能看到舊進度。本輪沒有證據顯示資料曾對外洩漏。

重現／核對方式：建立 R2 帳戶 → 數學作答 → 匯出／還原同孩子數學備份 → 回英文設定按清除目前帳戶資料 → 再開數學。

程式原因或現況：清除帳戶會重新建立同名識別碼 c_demo；數學清理橋接只比對哪些孩子 ID 被刪除，忽略保留 ID 但整個帳戶重設的情況。

建議修改：獨立處理帳戶重設事件；同步清除對應數學主資料及復原副本，重新建立記憶體狀態；任何寫入／刪除失敗可回復。

完成驗收條件：預設及多孩子帳戶分別重設後無殘留數學紀錄；失敗不顯示成功；未被操作的其他帳戶資料保持不變。

證據：targeted_checks.json:T15；reset_retains_math_viewport.png；source_excerpts/B01_reset.txt

完成驗收條件：獨立0.1.2→整合R2、同版換帳戶、多孩子、重複匯入均逐項對帳；沒有再次派幣或跨孩子污染。
