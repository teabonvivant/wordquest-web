# 開發交接與版本來源

## 交付性質

本次工作是收集、復原、拆出可讀資料、核對與打包；不是新一輪程式功能升級。不要把此包升級標籤為 V33、Maths 0.1.3、完整合併版或商用完成版。

## 英文 V32 的恢復

從同一份完整 HTML 文字快照取回第 1–4677 行，以 1–1000、1001–2000、2001–3000、3001–4000、4001–4677 五段重組。重組後為 12,441,050 bytes，與檔案紀錄大小相同，結尾完整，31 段腳本通過 Node 語法檢查。

這是可讀文字快照的復原。沒有原始檔案的獨立 SHA-256 可交叉核對，故不聲稱已證明與原 ZIP 逐 byte 一樣。

## 數學 0.1.2 的恢復

從完整 Installer HTML 中取出 `payload64`，Base64 解碼成 UTF-8 插件，保留原文為 `WordQuest_Maths_Plugin_0.1.2.html.txt`。獨立 HTML 只加入頁面外框並將 `WQM_INTEGRATED` 設為 false。4 段 JS 的數學、儲存與介面邏輯未改寫。

`02_Maths_0.1.2/source/curriculum.json` 是該 payload 的 `WQMathData`，不是從舊檢查包挪用的早期題庫。來源與雜湊在 PACKAGE_MANIFEST.json。

## 原始檢查的保留

`06_Original_1000_Audit/WordQuest_1000_Audit` 保持原有結構與全部檔案內容。原始 960/40 結果未被後來版本或本次 14 項冒煙檢查覆蓋。將來重跑應另建一個結果資料夾，明確記錄使用的 HTML SHA-256。

## 報告的限制

兩份較新歷史報告只有可讀原文被恢復；相應 ZIP、部分圖像與測試 JSON 未取得。`.source.html.txt` 保存取得的原文；`.html` 是另加範圍提示並停用缺件連結的閱讀副本。0.1.2 報告恢復文字的 byte 數與紀錄大小相差 10 bytes；沒有把它當成原始二進位檔一致性證據。

## 缺少的材料

優先補回 V33 Original Arcade 完整 ZIP、0.1.3 Character Features 完整 ZIP、新版數學角色原 PNG，以及 V33 Playtest Audit。檔名紀錄不能用作程式碼替代。取得後先建立來源雜湊，再比較版本差異，不要直接用 V32 覆蓋新版。

## 測試再現

日常使用無須 Python。開發者需要 Node.js 來執行 `node --check` 與 `08_Package_QA/extract_data.cjs`；瀏覽器冒煙測試使用 Python、Playwright 及 Chromium，可透過 CHROMIUM_EXECUTABLE 環境變數指定瀏覽器位置。

`package_browser_smoke.py` 明確使用隔離記憶體儲存；不能用其 PASS 宣稱原生持久化或正式部署驗收。歷史 1,000 項測試在原檢查資料夾，使用其 README 所列方式執行。
