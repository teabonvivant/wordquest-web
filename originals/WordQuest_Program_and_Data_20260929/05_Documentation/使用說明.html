使用說明

本包是可取得資料整理版。英文 V32 與數學 0.1.2 分開運作；不是 V33＋0.1.3 的最新完整整合版。

1．開啟程式

把 ZIP 完整解壓到一個固定資料夾，再開啟 START_HERE.html。選擇英文或數學入口。日常 HTML 使用不需要 Python。

不要只在 ZIP 預覽視窗內逐個開檔，否則說明書、素材或報告的相對路徑可能不完整。

2．先保留原有資料

你在舊版累積的孩子資料、進度及本機帳戶不會自動進入這個 ZIP。先從原版匯出備份，保留原程式及原瀏覽器資料；不要因新檔未顯示舊資料便清除瀏覽器。

英文與數學的儲存及獎勵沒有在這個包內合併。數學可由「家長設定」建立本機學習檔案；正式轉移資料前仍須驗證原生保存與還原。

3．哪些資料已包含？

英文完整 HTML、31 段腳本、可讀資料 JSON、數學完整插件及獨立入口、4 段脚本、數學題庫、495 個原有內嵌圖像、使用與開發文件、原 1,000 項檢查包全部檔案，以及本次核對記錄。

缺少 V33 原始套裝、數學 0.1.3 原始套裝、新版數學角色 PNG、相應缺失的歷史測試證據，以及你原本瀏覽器的學生資料。

4．不要把打包當成已修妥

此工作沒有改寫英文學習或遊戲程式，也沒有重跑原 1,000 項測試。數學 0.1.2 由既有整合器恢復；本次只建立獨立入口，沒有宣稱完成所有上次發現的問題。

整合器與本包 V32 有已確認的帳戶／錢包介面不相容，故沒有提供假裝已合併的頁面。

5．外部元件與語音

相片 OCR 的線上元件及部分外部讀音資源不是離線全套。裝置語音取決於瀏覽器可用聲線；本包沒有新增真人錄音。本次沒有真正 OCR、真人語音或原生下載測試。

整個包沒有 API 金鑰、雲端帳戶密碼或字型檔。
