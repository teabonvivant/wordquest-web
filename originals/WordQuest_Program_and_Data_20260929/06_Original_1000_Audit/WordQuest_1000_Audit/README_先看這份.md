# WordQuest｜1,000 項檢查套件

**本包是檢查結果，不是修正版或英文合併版。原程式沒有修改。**

檢查日期：2026-09-29

## 先看報告

直接打開 `report/WordQuest_1000_Checks_Report.html`。
看報告不需要安裝 Python、Node.js 或啟動伺服器；報告沒有外部圖片或字型依賴。

報告預設列出 40 個未通過案例。將狀態改為「全部」，可搜尋完整 1,000 項。
完整結果是 **960 通過、40 未通過，合併根源後 10 類問題**。

## 包含內容

- `report/`：可互動 HTML 報告、純文字 Markdown 報告、問題清單及来源／環境紀錄。
- `results/`：逐項結果、原始分批輸出、504 組出題資料與補充重現紀錄。
- `evidence/`：瀏覽器原始截圖；`review_*_settled.png` 是進場動畫完成後補拍的靜止畫面。
- `source/`：本次受測的 Maths 0.1.0 索引全文快照及逐段抽出的原程式，未作修補。
- `tests/`：可重跑的核心、獨立數學答案和實際瀏覽器操作測試。
- `SHA256SUMS.txt`：包內檔案校驗碼（不包含 ZIP 本身）。

## 必須保留的範圍限制

受測版本只有數學／奧數獨立試用版；V33 ZIP 原始內容未取得，沒有完成英文↔數學合併驗收。
來源是 Library 可讀取的完整索引文字，208,912 bytes；大小與清單一致、HTML 尾段完整。
它不是已驗證與原始 ZIP 位元組完全一致的副本。

瀏覽器在 Chromium 144.0.7559.96 執行，使用實際 DOM click/fill/keyboard。
由於測試環境不允許 file:// 或 localhost 導航，以 set_content 載入 HTML，並注入隔離記憶體 localStorage。
因此沒有聲稱驗證真實瀏覽器持久保存、部署、Android/iPhone/Safari、真實跨分頁同時寫入或雲端。
音效有事件及 WebAudio 音符證據，沒有真人聽感／粵語發音驗收。

1,000 是唯一測例數，不是 1,000 個獨立功能；參數化案例已列明。
同一根源可影響多個案例；重跑與補充截圖不另加數目。
全部學員資料是為本輪測試建立的虛構資料。

## 重跑方法（只看報告不用做）

本次環境：Python 3.13.5、Node.js v22.16.0、Python Playwright、Chromium。
重跑須有上述工具或相容版本；沒有把依賴程式或瀏覽器安裝檔打包。

在套件根目錄執行：

```text
python tests/run_all.py
```

需要時以環境變數 `CHROMIUM_PATH` 指定 Chromium/Chrome 執行檔。
測試在獨立瀏覽器 context 運行，不會連接你的個人瀏覽器或正式網站。

原版本已知存在 40 個失敗案例，所以完整重跑預期返回 exit code 1。
這代表發現待修正項目，不是測試已經全部通過。
修正原程式後，可用同一組 ID 重跑；新結果寫入 results/。
包內 HTML／Markdown 是本次基線報告，不會因為重跑而自動改寫。
不同瀏覽器版本可能出現新的相容性差異，需按實際輸出再判斷。

`build_report.py` 用於整理本輪固定基線，不用它宣告未來版本的修正結果。
`tests/supplemental_evidence.py` 是補充故障重現及截圖，不列入 1,000 項總數。
