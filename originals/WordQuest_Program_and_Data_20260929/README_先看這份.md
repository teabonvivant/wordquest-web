# WordQuest 程式及資料整合包

**日期：2026-09-29。這是可取回資料的整理與復原包，不是最新完整優化版，也不是商用驗收版本。**

## 先開哪一個？

先把整個 ZIP 解壓，再用瀏覽器開啟根目錄的 **START_HERE.html**。

英文入口是 `01_English_V32/WordQuest_V32_Integrated.html`；數學入口是 `02_Maths_0.1.2/WordQuest_Maths_0.1.2.html`。
日常開啟 HTML 不需要 Python。Python、Node.js 及 Playwright 只供開發者重跑包內測試或重新抽取資料。

## 必須分清的版本狀態

- 英文：完整 V32 HTML 文字快照已恢復，保留內嵌題庫、角色圖像、原有遊戲與原始碼。**不是 V33**，沒有將 V32 改名冒充新版。
- 數學：從原有 0.1.2 整合器的內嵌 HTML payload 恢復。獨立入口只增加 HTML 外框，將 `WQM_INTEGRATED=true` 改為 `false`，没有改寫題庫或判分邏輯。**不是 0.1.3 森林學院角色版**。
- 兩者在此包內**獨立運作**，沒有共用孩子帳戶、星星／金幣錢包或合併學習報告。
- 本次沒有重新執行原來的 1,000 項檢查，也沒有宣稱上次 10 類問題全部已修妥。

已找到但仍未能取回原始檔的主要資料：`WordQuest_V33_Original_Arcade_Package.zip`、`WordQuest_Maths_0.1.3_Character_Features.zip`、`WordQuest_V33_Playtest_Audit_Package.zip`，以及新版數學角色 PNG 原圖。這些不是本 ZIP 的內容；只能保留缺件紀錄及已恢復的報告文字。

## 已做與未做的驗證

35 段 JavaScript 語法檢查通過。495 個抽出圖像的雜湊及解碼檢查通過。原始檢查包 70 個檔案已逐一與原 ZIP 比對，內容一致。

本次另做 14 個 Chromium DOM 冒煙檢查，涉及英文／數學首頁、手機闊度、圖像載入、角色／街機入口及數學建立測試學員、出題、實際填答和寫入隔離儲存。這些是有限流程檢查，不能當作所有功能驗收。

本環境的瀏覽器政策阻止 `file://` 直接導航，所以瀏覽器測試採用 `set_content` 加隔離的記憶體 localStorage 替身。**沒有完成你電腦上的原生檔案開啟、原生 IndexedDB、下載、長期保存、真手機、Safari、真人語音或真正 OCR 驗收。** 截圖是實際 Chromium 畫面，不是效果示意圖。

原始 1,000 項檢查結果仍為 **960 通過／40 失敗**，檢查對象是包內保留的早期數學版，不能套用到英文 V32 或恢復的數學 0.1.2。

首次打包冒煙檢查中，手機頁面尚未捲到的延遲載入圖像被當成載入失敗。已保留首次結果與當時圖像狀態；修正測試流程，先捲動觸發載入後再核對，14 項通過。沒有因此改寫英文程式或掩蓋原始檢查結果。

## 整合器的已知限制

實際試過把現有 0.1.2 插件直接注入 V32：英文主程式的孩子／帳戶函式位於封閉作用域，插件無法取得需要的帳戶及錢包介面，會顯示「未能識別這個英文版本的帳戶或錢包介面」。因此本包沒有提供假裝已合併的主程式。`03_Installer` 只保留原整合工具，供之後正式改接及驗收。

## 學習進度、OCR 與外部資料

這個 ZIP 包含程式資料，不會自動包含你原本瀏覽器的學生進度、家長帳戶或本機資料庫。轉用其他檔案前，先從原版匯出備份；不要刪除舊程式或清除瀏覽器資料。

原英文程式仍保留線上 OCR 元件及外部讀音來源的載入路徑；相關外部服務、OCR 模型／CDN 執行元件與真人音檔沒有因打包而全部內置。未驗證這些外部服務。包內沒有 API 金鑰、雲端帳戶密碼或字型檔。

## 資料保存與修改

原程式仍保留內嵌圖像，所以只開啟英文 HTML 不依賴抽出的素材資料夾。抽出的 JS／CSS／JSON／圖像副本方便閱讀和修改；**改副本不會自動改變原單檔**。正式開發應建立可重現的建置流程，再把改動寫回單檔並回歸驗證。

舊版素材的來源與授權註記保留在原碼及程式的素材來源頁；本次整理沒有另行授予第三方素材的權利，也沒有重新逐項驗證其授權。
