# 不是已驗收的合併入口

此處保留原有 WordQuest Maths 0.1.2 Installer，未改寫其內容。

本次實際 DOM 測試確認：直接注入本包 V32 時，`WQMathApp.hostConnected()` 為 false，插件顯示帳戶／錢包介面未能識別。因此不要把整合器「成功產生 HTML」當作真正合併成功。

主要原因是 V32 的 `activeChild`、`accountId`、`isLoggedIn`、`save`、`db` 在主程式的封閉作用域內；插件在另一段腳本內不能直接存取。正式整合需要由主程式提供明確且受限制的橋接介面，並實測孩子切換、存檔失敗、錢包結算、重複發放、遊戲暫停和多分頁衝突。

本包提供的兩個程式入口保持獨立，沒有修改或共用原來的錢包。
