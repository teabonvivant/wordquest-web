1　先保留英文原檔及資料備份

先在原英文程式匯出資料。解壓英文程式的 ZIP，找出可以開啟的 .html 主檔，再在下面選取它。

只接受 HTML，最大 80 MB。這個工具不會執行你選取的原程式。

2　產生另一份整合檔案

新檔會加入「＋ 數學／奧數」入口；數學在獨立視窗層顯示，返回後保留英文畫面。可識別的原帳戶、孩子和錢包會經轉接器重用，數學進度另作旁存。

3　先用測試孩子驗收

開啟新 HTML，按「＋ 數學／奧數」，確認孩子名稱和金幣與英文一致。完成一課、關閉重開、切換孩子，再檢查英文原功能仍然正常。

本機 file:// 儲存的範圍由瀏覽器決定，新檔名或位置可能看不到原帳戶。不要因此重新建同名孩子去覆蓋舊資料。保留原檔；先用原英文匯出的備份還原到測試副本。

數學也要在「家長與進度」獨立匯出備份。原英文的備份不包含數學旁存資料。本版未部署到 GitHub 或伺服器。
