# WordQuest V32＋數學 0.1.2｜整合 R1

這是本輪實際套用的版本，不是只把兩個獨立網頁放在同一個 ZIP。

## 開始使用

1. 將整個 ZIP 解壓到一個固定資料夾，不要在壓縮檔預覽內執行。
2. 開啟 `START_HERE.html`，按「開啟英文＋數學整合版」。已建好的程式在 `app/index.html`，不需要 Python。
3. 已有英文帳戶可沿用相同網址／瀏覽器內的原有登入資料；新環境則先建立測試帳戶。孩子首頁上方新增「普通數學」「奧數思維」「數學學習主頁」。

Windows 另附 `START_WINDOWS.cmd`，使用系統 PowerShell 在 **127.0.0.1:8765** 提供本機網址並開啟瀏覽器，不安裝 Python／Node，不要求管理員權限，不對外網開放。保持黑色視窗開啟，關閉即停止。本輪沒有 Windows 真機執行環境，此啟動器列為**未實機驗證**。被公司／學校安全政策阻擋時，不要關閉安全防護；可交由網站管理員部署 `app/index.html`。

`file://`、`http://127.0.0.1:8765`、不同網域及不同瀏覽器的保存位置不相同。改路徑或改啟動方式前先備份；本程式不會自動取走舊頁面或另一部電腦的資料。

## 這次真正套用了甚麼

- 英文 V32 保留原有帳戶、孩子、單字、練習、街機、角色及素材；數學 0.1.2 插件已嵌入同一份 HTML。
- 在英文程式封閉作用域內加入 `WQMathHost` 專用橋接，數學讀取目前英文孩子；不再另外建立數學帳戶。
- 數學／奧數合資格課堂使用原有 V32 金幣派發規則。每日規則及上限與英文共用；重複結算不重派。
- 英文家長頁新增數學摘要。普通數學及奧數作答、掌握度保持分開；不是把兩科評分混成一個數字。
- 數學設定、備份及完成頁的「查看學習進度」沿用英文家長驗證。
- 使用原有 V32 圖像與角色身份作數學陪伴，不改判分、不假冒缺失的 0.1.3 角色套件。
- 補上缺題課堂拒絕恢復、訪客同頁草稿保留、失敗儲存退出提醒、鍵盤回饋焦點、孩子刪除時數學資料與復原副本一併清理。

## 版本來源

本輪能完整讀取並套用的基礎是 **英文 V32＋數學 0.1.2**。來源為上一輪已交付的 `WordQuest_Program_and_Data_20260929.zip`；當中英文 HTML 為完整取回的文字快照，數學插件來自 0.1.2 整合器保存的有效載荷。不是重新取得 V32 完整 ZIP 原件。

重新嘗試取得英文 V33、V33 審核包、數學 0.1.3、V32 完整套件、V31 及數學 0.1.2／0.1.1 的 ZIP 原件，仍無法取得獲授權的原始位元組。因此沒有把版本號改成 V33 或 0.1.3。`R1` 是本輪新增接駁及修正的標記，不代表官方後續版。

新版六張數學角色原圖未取回。沒有重新生成或冒充原圖。所有可用旧版資料保存在 `originals/`；新程式不以這些舊報告的「通過」字樣作本輪驗收結論。

## 備份與遷移：先保護原資料

- **英文備份**：在原英文程式家長／設定頁匯出，包含英文資料及英文金幣錢包。
- **數學備份**：在數學家長頁匯出，包含目前英文孩子的數學／奧數進度。金幣不會因還原數學備份再派一次。
- 本版仍是兩份科目備份，不是自動一鍵跨科完整備份。ZIP 內不含你個人電腦瀏覽器原有的學員紀錄或密碼。
- 舊「獨立數學版」孩子 ID 與英文帳戶不一定相同。整合版拒絕不同孩子擁有者的備份，**不會猜測孩子配對後自動合併**。需要保留原備份，由管理員核實擁有者後另做遷移。
- 保留 V33／0.1.3 的原檔及備份；不要用本版覆蓋或匯入較新版本的未知資料結構。

## 測試界線

詳見 `docs/本輪套用及驗證報告.html`。本輪使用真正 Chromium DOM 點擊、填答、鍵盤操作及不同視窗寬度；但執行環境禁止 `file://` 及 HTTP 導航，測試以 `page.set_content()` 載入完整 HTML，儲存、Web Locks 及 WebCrypto 呼叫介面使用明確標示的測試轉接器。

因此，不把本輪結果當成原生跨分頁鎖、真正瀏覽器重啟保存、Windows 啟動器、Safari／iPhone／Android、相機／OCR／外部 CDN、網絡登入、真人音效與粵語音質已通過。本版沒有雲端伺服器，也不是正式考試防作弊平台。

數學仍只有 **23 個普通數學入門技能＋5 個奧數主題、84 個模板**。不是小一至小六全課程，未完成內容保留待開發標示。英文 V33 的原創街機升級、Maths 0.1.3 新角色功能沒有被悄悄補上。
