# WordQuest R3.4 · 街機手感與手機玩法

## 這次交付

在 R3.3 之上增量改良街機：26 款遊戲的手感、規則公平度，以及手機（尤其橫屏）玩法。**這不是商用版**：沒有新增會員、教師審核、學習整合；商用差距與遊戲評測見 `docs/R3_4_商用差距與遊戲評測.md`。

和 R3.3 一樣不是手改的 12 MB 檔案：`app/index.html`、`app/sw.js` 由 `tools/build_r34.py` 先重建 R3.3（`tools/build_r33.py` 加凍結的 R3.2 原件），再套 `r34_src/patches/` 三個補丁模組。每個錨點必須剛好出現一次，否則建置失敗；`<script>` 數量必須不變；版本由核心統一改為 R3.4.0。

| 補丁 | 內容 |
| --- | --- |
| `p10_feel` | 手感層 `WQFX`：分數彈出、連擊橫幅、受傷震屏與閃光、升級彩帶、手機震動；準備畫面顯示目標與玩法；結算畫面顯示分數、最高分、新紀錄、星星；勝、過關、敗三種結算音；設定內「動感效果」開關，尊重減少動態 |
| `p20_engines` | 26 款遊戲的規則、難度、提示、音效與主機規則修正（見下表），每項都有「改前 vs 改後」比對 |
| `p30_touch` | 手機玩法層：橫屏雙側操作區、畫面手勢、直放提示、橫放自動放大 |

## 手機玩法

- **橫屏**：放大後畫面由約 409×286 增至約 529×370（844×390 手機）。左側是方向鍵（十字）和該遊戲的工具按鈕，右側是分數、動作鍵和暫停／離開／說明／還原；標題與底列折入兩側，畫面用滿整個高度。R3.3 在橫屏隱藏的遊戲工具現在顯示。
- **橫放自動放大**：觸控裝置橫放時自動進入放大模式，直放自動退出；手動按「還原」後，要再轉動手機才會自動放大。直放時（工具多的遊戲除外）顯示一條可關閉的「橫放手機，畫面更大、更好玩」。電腦滑鼠不受影響。
- **畫面手勢**（只加在畫面本身不接受手指的 9 款動作遊戲；其他遊戲沿用引擎本來的觸控，只補提示文字）：

| 遊戲 | 手勢 |
| --- | --- |
| 森林跑酷、遺跡郵差 | 左右滑一下＝換一條跑道；輕按＝跳躍；向下滑＝滑行；第二隻手指按下＝即時跳躍（按住不放高跳） |
| 雲島探險 | 左右拖動移動；輕按跳躍 |
| 海港排球 | 左右拖動移動；輕按擊球；向上滑跳躍；向下滑打短球 |
| 燈塔深井 | 左右拖動移動；輕按開降落傘；向下滑加速落下 |
| 山谷賽車 | 左右拖動轉向；向下一滑按住煞車 |
| 天空救援隊、星環巡航 | 手指拖動飛行；輕按開護盾 |
| 漂移路線 | 按住畫面任何位置轉彎 |

手勢只是呼叫與螢幕按鈕相同的輸入入口（`a28Input`），所以暫停、存檔、結算規則全部不變；暫停、取消觸控或一局結束時不會卡鍵。只有 `a28Motion` 內的遊戲才會啟用手勢，不會和引擎自己的觸控重複。

主機規則：完成的漂移路線與月亮攀登算成功；`a28Motion`／`a28PointerGames` 兩個集合修正（引擎自己讀手指的遊戲交還引擎；彩球工房不再有無用的虛擬游標）；重試保留分數；所有 R2 配樂音量加倍（原來比音效低約 14 dB，推算，未用人耳驗證）。

## 需要擁有者決定的政策（我已盡量不碰）

一局一幣、每輪五幣、生命數**全部不變**。只做了「兒童友善的免費探索」，如不同意，刪掉 `r34_src/patches/p20_engines.py` 內對應的項目後重建：彩球工房兩次免費驗收（`cw-free-checks`）、小小工程師返回設計免費（`le-free-return`、`le-stuck*`）、果汁畫線「重新裝水」與彩球工房「還原白球」改為免費工具（`jl-tool-id`、`cw-tool-id`）、重試保留分數（`retry-score`）、數字花園目標降低（`ng-target`）。

## 重建與測試

```sh
python3 tools/build_r34.py                         # 重建 app/、server/（r34_evidence/build.json 記錄雜湊）
python3 tools/build_r34.py --only p10,p20 --out /tmp/x   # 只套某些補丁，供開發
python3 tools/build_r34.py --base-only --out /tmp/r33    # 只輸出 R3.3 文字（A/B 對照用）
python3 r34_tests/run_release.py                   # R3.4 新測試，逐項依序執行（不要並行）
python3 r34_tests/run_behaviour.py                 # 「改前（R3.3）應失敗、改後應通過」的 A/B 證明
python3 tools/package_r34.py                       # 重新產生 PACKAGE_MANIFEST.json 與 SHA256SUMS.txt
```

任何測試都可用 `WQ33_APP=/path/index.html`（瀏覽器）或 `WQ34_APP=...`（Node）指定被測檔案。舊測試仍可執行，會覆寫自己的證據資料夾，執行後請用 `git checkout -- <證據資料夾>` 還原。

| 範圍 | 檔案 |
| --- | --- |
| 26 款引擎逐款行為（改前改後比對） | `engine_behaviour.cjs` |
| 26 款 × 3 難度 × 2 種子隨機遊玩，存檔點必須有效 | `engine_validity.cjs` |
| 真實瀏覽器：26 款開局、遊玩、暫停存檔；勝負判定；彩球工房免費驗收；動感開關；一局一幣 | `browser_rules.py` |
| 真實瀏覽器：準備卡、結算卡、星星、新紀錄、結算音、動感開關、減少動態 | `browser_feel.py` |
| 真實瀏覽器（Chromium 觸控模擬、真實 DevTools 觸控事件）：四種橫屏尺寸版面、直放／橫放切換、各遊戲手勢、不卡鍵 | `browser_touch.py` |

`[B]` 標記的檢查在 R3.3 上必須失敗，在 R3.4 上必須通過；`run_behaviour.py` 兩邊都跑並核對。

## 已知限制與未驗證

- **沒有真機**：所有手機測試是 Chromium 觸控與手機尺寸模擬（844×390、932×430、667×375、740×360 橫屏及 390×844 直屏）。iPhone 的 Safari 一般不支援網頁全螢幕，橫屏放大不依賴全螢幕，但地址欄伸縮、軟鍵盤、「加入主畫面」都沒有實測。
- **沒有真人兒童與人耳驗證**：手勢距離與時間門檻、結算音、震動強度只以程式斷言，要由真人調整。
- 遊戲吸引力分數是我的設計師判斷，不是玩家數據。
- **沒有改的**：學習連結（遊戲與英文、數學內容脫節）、「一局一幣」的重玩動機、角色貫穿全部遊戲、預錄音效與配樂、卡通結算動畫、街機大堂的進度展示。
- 手勢只加在 9 款動作遊戲；工具多的遊戲（彩球工房、森林節奏社、甜點夢工場、小小工程師）橫屏時工具按鈕在左側欄內捲動，直放仍較好用。
- 星星節奏的延遲校準靠預備拍的輕拍；不拍或亂拍時不會改變延遲。
