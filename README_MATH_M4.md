# HK-M4 classroom revision

The existing 170 chapters now have classroom scaffolds: 158 ordinary assessment chapters and 12 ungraded exploration chapters. The addition preserves the existing family/account storage and the original English, games and Olympiad modules.

Each chapter has a prerequisite question, specific visual model, short teaching steps, vocabulary, a tool task, a teach-back prompt, misconception repair and optional teacher notes. Guided answers and the drawing/grid/counter/number-line workpads do not award mastery or coins. Existing independent tests retain first-attempt records.

The editable content is `math_course_src/classroom-lower.json` and `classroom-upper.json`. `classroom_bundle.js`, `app/index.html`, the standalone preview and CSS/tool bundles are generated by `python tools/build_math_m1.py`. Do not edit those generated copies directly.

Teaching corrections include whole-hour clock alignment, same-denominator fraction addition, one-step balance equations, the reason for multiplying by the reciprocal, visible fractional-area intersections, and separate capacity/displacement examples. Original historical question IDs and answers are retained.

Validation:

- `node math_course_tests/classroom_test.cjs`: all chapter packs, safe diagrams, original-script preservation and corrected mission configurations.
- `node math_course_tests/pedagogy_test.cjs`: taught/assessed scope, actual worked calculations, fractional figures and answer-history preservation.
- `node math_course_tests/engine_test.cjs`: scoring, storage and generated question cases.
- `node math_course_tests/visual_ui_test.cjs`: production renderers/events for all chapters; this is a DOM-stub check, not browser layout testing.

The audits in `math_course_evidence/classroom-*-audit.json` distinguish active content, historical examples, practical-tool limits and official scope. The material covers the implemented chapters; it does not certify complete coverage of every official learning objective. Representative desktop/mobile browser checks are recorded separately from automated content checks. No child usability study has been conducted in this revision.
